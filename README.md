# 드래곤 특공대 (Dragon Force)

레드 드래곤이 검은 왕관의 파편에 오염된 마수 지역(1~10단계)을 지나, 드래곤의 심장을 노리는 인간 왕국(11~20단계)과 싸우는 로그라이크 서바이버 슈팅 게임. 시즌 1의 5개 챕터 1~20단계(쉬움)를 플레이할 수 있고, 판마다 얻은 골드로 드래곤을 영구 강화한다.

- 자동 공격 + 이동만 조작 (PC: WASD·방향키 / 휴대폰: 화면 끌기)
- 레벨업마다 스킬 3개 중 1개 선택
- 드래곤 10종(화염·얼음·번개·독·빛·암흑·대지·바람·물·신비): 고유 기본 공격 Lv.1~7과 특성, 영구 Lv.40(5레벨마다 공격 방식 변화), 5성 승급, 직접 누르는 전용 액티브
- 루비 상점(드래곤·스킬 / 장비 / 골드 상자, 확률 공개·천장), 장비 4슬롯·합성, 장착형 특수 스킬 15종, 전투력·권장 전투력, 3난이도 진행도 보상, 일일·주간·월간 미션
- 몬스터가 가끔 떨어뜨리는 아이템: 스킬 강화 상자·회복 물약·경험치 자석·용의 수호막
- 판이 끝나면 골드 정산 → 성장 연구소에서 공격력·HP·비행속도·흡수 반경 영구 강화
- 웹(Phaser 4 + TypeScript + Vite)으로 만들고, iOS는 Capacitor로 감쌀 예정

AI(Claude Code)와 협업해 만들고 있으며, 단계별로 무엇을 AI에게 맡기고 무엇을 직접 판단했는지 기록한다.

## 실행
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:5173 을 연다. `?seed=123`을 붙이면 같은 적 생성이 재현된다. `npm test`로 성장·골드·저장·상점·장비·미션·이벤트·스테이지 데이터 테스트(101개).
