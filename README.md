# 드래곤 특공대

인간 왕국에게 멸망한 드래곤이 다시 깨어나, 몰려오는 기사·마법사·골렘 군단을 물리치고 성지를 되찾는 로그라이크 서바이버 슈팅 게임.

- 자동 공격 + 이동만 조작 (PC: WASD·방향키 / 휴대폰: 화면 끌기)
- 레벨업마다 스킬 3개 중 1개 선택
- 웹(Phaser 4 + TypeScript + Vite)으로 만들고, iOS는 Capacitor로 감쌀 예정

AI(Claude Code)와 협업해 만들고 있으며, 단계별로 무엇을 AI에게 맡기고 무엇을 직접 판단했는지 기록한다.

## 실행
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:5173 을 연다.

- [x] 1단계: 드래곤 이동(키보드·터치)
