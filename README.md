# 드래곤 특공대 (Dragon Force)

레드 드래곤이 검은 왕관의 파편에 오염된 마수 지역(1~10단계)을 지나, 드래곤의 심장을 노리는 인간 왕국(11~20단계)과 싸우는 로그라이크 서바이버 슈팅 게임. 지금은 1단계 잿빛 숲까지 플레이할 수 있고, 판마다 얻은 골드로 드래곤을 영구 강화한다.

- 자동 공격 + 이동만 조작 (PC: WASD·방향키 / 휴대폰: 화면 끌기)
- 레벨업마다 스킬 3개 중 1개 선택
- 몬스터가 가끔 떨어뜨리는 아이템: 스킬 강화 상자·회복 물약·경험치 자석·용의 수호막
- 판이 끝나면 골드 정산 → 성장 연구소에서 공격력·HP·비행속도·흡수 반경 영구 강화
- 웹(Phaser 4 + TypeScript + Vite)으로 만들고, iOS는 Capacitor로 감쌀 예정

AI(Claude Code)와 협업해 만들고 있으며, 단계별로 무엇을 AI에게 맡기고 무엇을 직접 판단했는지 기록한다.

## 실행
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:5173 을 연다. `?seed=123`을 붙이면 같은 적 생성이 재현된다. `npm test`로 성장·골드·저장 규칙 테스트.

## 진행 상황
- [x] 1단계 전투 프로토타입: 드래곤 이동 → 몬스터 추적 → 자동공격 → 체력 → 죽음
- [x] 2단계 Survivor 시스템: 경험치 → 레벨업 → 랜덤 스킬 3개 중 선택
- [x] 3단계 스킬 시스템: 레드 드래곤 추적 화염탄 Lv.1~7 + 액티브 6종(화염·얼음·번개·메테오·오브·날개 폭풍) + 패시브 8종 (기획서 v0.2)
- [x] 4단계 엘리트·보스·클리어: 1단계 잿빛 숲 8분(엘리트 1:40·3:40, 보스 5:50, 7:30 격노, 8:00 실패), 원형 투기장, 결과 화면·다음 단계 해금
- [x] 5단계 영구 성장: 로비 · 드래곤 성장 연구소(공격력·HP·비행속도·흡수 4종) · 골드 정산(클리어 340~460G, 실패 50%) · 일시정지/포기 · 브라우저 저장 · 전투 아이템 4종 드롭
- [ ] 6단계 아트/사운드
- [ ] 7단계 모바일 최적화
- [ ] 8단계 스토어 출시
