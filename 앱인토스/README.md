- 브랜치: `apps-in-toss` (작업 폴더: 제작자 PC `C:\Users\t0105\dragon-force-toss` — OneDrive 밖. OneDrive 안에서는 git이 `mmap failed`로 멈춤)
- 앱 이름(appName): `dragon-force` (한 번 정하면 못 바꿈, `apps-in-toss.config.ts`)
- 빌드: `npm run build:toss` → `dragon-force.ait` (git에는 안 올림, `.gitignore`)
