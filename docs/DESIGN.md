# 드래곤 특공대 — 게임 설계

> 이 문서의 세계관·루프·스킬·MVP 범위·개발 순서는 제작자(오준수)가 정한 것이다(2026-11-17).

## 세계관
인간 왕국에게 멸망한 드래곤들이 다시 깨어나 자신들의 성지를 되찾는다.
플레이어는 여러 속성의 드래곤을 골라 몰려오는 기사·마법사·골렘·몬스터 군단을 상대한다.

(개발 4단계 기획서, 2026-11-17) 1~10단계는 인간 왕국에서 흘러나온 "검은 왕관의 파편"에 오염된 마수 지역, 11~20단계는 드래곤이 마수 사태를 일으켰다고 선전하며 군대를 보내는 인간 왕국. 왕은 마수의 힘과 드래곤의 심장으로 영원한 힘을 얻으려 한다. 20단계 최종보스는 용사냥왕 아스테리온. 상세는 `docs/STAGE.md`.

## 한 판의 흐름 (약 8~10분)
전투 → 경험치 획득 → 레벨업 → 스킬 3개 등장 → 하나 선택 → 보스 → 보상 → 영구 성장

## 스킬 후보
| 스킬 | 효과 |
|---|---|
| 🔥 화염 브레스 | 전방 범위 공격 |
| ⚡ 번개 숨결 | 적 사이 연쇄 공격 |
| ❄️ 얼음 파편 | 공격 + 둔화 |
| 🌪️ 날개 폭풍 | 주변 적 밀쳐냄 |
| ☄️ 드래곤 메테오 | 일정 시간마다 광역 공격 |
| 🐲 드래곤 오브 | 주변을 회전하며 공격 |
| 🛡️ 용의 비늘 | 피해 감소 |
| 🔥 화염 강화 | 화염 공격 피해 증가 |

나중에: 스킬 진화 (예: 화염 브레스 Lv.5 + 용의 심장 → 지옥화염 브레스)

## 첫 MVP (진짜 작게)
- 드래곤 1마리
- 일반몹 3종 + 보스 1종
- 스킬 6개
- 스테이지 1개
- 레벨업 시 3택
- 게임오버 / 클리어
- 간단한 강화(영구 성장)

## 핵심 루프
플레이어 이동 → 적 생성 → 자동 공격 → 적 사망 → 경험치 획득 → 레벨업 → 스킬 3개 중 선택

**이 루프가 재미있으면 그때 그림을 넣는다.**

## 개발 순서
1. 전투 프로토타입 — 드래곤 이동 → 몬스터 추적 → 자동공격 → 체력 → 죽음
2. Survivor 시스템 — 몬스터 처치 → 경험치 → 레벨업 → 랜덤 스킬 3개 → 하나 선택
3. 스킬 시스템 — 화염 / 얼음 / 번개 / 메테오 / 오브 / 방어
4. 스테이지 — 시간에 따라 몬스터 증가 → 엘리트 → 보스 → 클리어
5. 성장 — 게임 종료 → 골드 정산 → 성장 연구소에서 공격력·HP·비행속도·흡수 반경 영구 강화 (`docs/GROWTH.md`)
6. 드래곤 — 10종 고유 기본 공격·특성, 소환·레벨·승급 (`docs/DRAGONS.md`)
6. 아트/사운드 — 드래곤 캐릭터, 애니메이션, 배경, 효과음, 이펙트
7. 모바일 최적화 — Android/iPhone 빌드 → 해상도 → 터치 → 프레임 → 발열 → 저장 확인
8. 스토어 출시

큰 틀은 제작자가 정하고, 단계 사이의 세부(수치·적 행동·UI 배치 등)는 AI가 제안해 구현한 뒤 제작자가 플레이해 보고 조정한다.

## MVP 다음 순서
1스테이지 → 3스테이지 → 드래곤 3종 → 장비 → 일일미션 → 광고 → 인앱결제

상점·뽑기·출석·길드·서버부터 만들지 않는다. 핵심 전투 루프가 재미있어야 나머지가 의미 있다.

## 만들지 않는 것
장르(자동 공격·몰려오는 적·레벨업 3택 서바이버)만 참고하고, 다른 게임의 이름·캐릭터·그림·레벨은 쓰지 않는다.
그림은 코드로 그린 도형으로 시작한다(`src/textures.ts`).
