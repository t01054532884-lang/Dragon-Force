## 1. 공통 수정(9장 모두)
1. **기존 10종과 같은 SD 비율**: 기존은 머리가 크고 몸이 짧은 아기 용(큰 눈). 시안은 목·다리가 길고 디테일이 많은 "큰 용" 느낌이라 도감에 섞이면 다른 게임처럼 보임 → 기존 레드 초상(`public/art/portrait-red.webp`)을 함께 첨부하고 "이 그림과 같은 비율·화풍"으로.
2. **크기·여백**: 지금 캐릭터가 캔버스의 91~100%(날개·꼬리가 가장자리에 닿음). 기존처럼 **캐릭터 85% + 아래 둥근 받침 그림자**(기존 초상 발밑의 남색 타원)로.
3. **투명 배경 깨끗하게**: 샌드(13%)·미러(22%)·크로노(7%)는 캐릭터 뒤에 **회백색 반투명 안개**가 깔려 있음 → 어두운 게임 화면에서 회색 구름으로 보임. 빛·반짝임 효과도 캐릭터 몸 가까이만.
4. 1024×1024 PNG 투명, 글자 없음(지금과 같음).
