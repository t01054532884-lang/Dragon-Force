# UI 디자인 시스템 (design/ui 브랜치)

v1.2 기능 개발(main, 옆 세션)과 겹치지 않게 별도 브랜치·별도 폴더(`Dragon-Force-design`)에서 만든다.
화면 파일(`src/scenes/*`)은 v1.2가 바꾸는 중이라 건드리지 않고, **새 파일만** 추가한다. v1.2가 main에 커밋된 뒤 화면에 입힌다.

## 보는 법
```bash
npm run dev -- --port 5174
```
http://localhost:5174/gallery.html — 아래 탭 바로 로비(전투) · 상점 · 드래곤 · 장비 · 부품(연구소 칸) 시안 전환, 로비 왼쪽 "출석"은 출석 팝업(`?page=shop`처럼 바로 열기도 가능).
시안의 숫자·이름은 보기용 예시이고 데이터와 연결돼 있지 않다. 배포 빌드에는 들어가지 않는다(Vite는 `index.html`만 빌드).

## 참고 화면 반영 (2026-11-18, 제작자가 준 장르 참고 스크린샷 8장)
- **가져온 것(장르 공통 구조)**: 맨 위 재화 줄(+ 버튼) · 맨 아래 탭 바(선택 탭은 노란 바탕·크게·이름) · 새 소식 "!" · 등급 색 머리띠 카드(이름·아이콘·레벨·조각 진행) · 리본 구역 제목 · 3칸 상품 카드와 가격 버튼 · 로비의 단계 배너/전투력/진행도 25·50·100% 상자/큰 노란 "전투 시작" · 출석 7일 격자 · 굵은 어두운 외곽선과 두께 있는 버튼.
- **가져오지 않은 것**: 그 게임의 그림·아이콘 모양·배치를 그대로 따라 그리지 않음(장르만 참고 원칙, 애플 4.1 모방 위험). 현금 패키지·"필수 구매"·"최대 3600% 혜택" 같은 문구·광고 보상·룰렛(첫 출시는 결제·광고 없음, 토스 다크패턴 금지).
- **색은 우리 것**: 참고 화면의 밝은 보라·초록 대신 어두운 남보라 + 용암 주황·금색.

## 원칙
- **오른쪽 위 비우기**: 토스 앱 안에서는 더보기·닫기 버튼이 오른쪽 위에 있다. 안전 영역 처리로 게임 화면이 그 아래로 내려가지만, 머리줄의 중요한 버튼은 왼쪽에 둔다.
- **누를 수 있는 것은 두께가 있다**: 버튼은 아래쪽 두께가 있고 누르면 내려간다. 패널·배지는 납작하다.
- **색으로 뜻 구분**: 전투 시작 같은 주 행동 = 용암 주황, 상점·소환 = 보라, 성장(강화·연구소) = 청록, 위험(포기·초기화) = 빨강, 그 밖 = 회색.
- **등급 색은 바꾸지 않는다**: 기본·일반·희귀·영웅·전설 5색은 게임 전체(소환·도감·장비)에서 같다.
- **정보 화면 배경은 조용하게**: 로비만 그림 배경, 상점·장비·도감은 그라데이션만.
- 글꼴은 `Pretendard → Apple SD Gothic Neo → Noto Sans KR → sans-serif` 순서. 앱에 글꼴 파일을 넣을지는 출시 전 결정(외부 글꼴 서버에 의존하지 않기 위해).

## 그림 연결 순서 (그림이 오면)
1. `art-src/`의 원본 → 크기 줄이기·여백 정리·PNG 압축 → `public/art/`
2. `src/ui/art.ts`의 `ART_FILES`에 키와 파일명 추가 → 시안 페이지에서 확인
3. 앱 아이콘: iOS `ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png`(1024×1024), 토스 로고 600×600, 토스 썸네일 1932×828

## 기록 (AI 협업)
- **제작자 판단**: v1.2 개발과 나란히 디자인을 진행, 별도 브랜치로. 그림은 기획자가 GPT 이미지로 생성해 주기로 함.
- **AI가 맡은 것**: 같은 폴더에서 옆 세션이 작업 중인 것을 확인하고 충돌을 피하려 별도 작업 폴더(git worktree)를 제안. 디자인 토큰·UI 부품·시안 3화면(로비: 재화·출격 드래곤·전투력 vs 권장·단계·난이도 / 상점: 상자 3종·1회·10회·보장 진행·확률 팝업 / 장비: 4슬롯·보유 목록·강화·합성), 그림 요청서.
- **확인**: 타입 검사 통과, 시안 페이지 4탭 브라우저 확인(콘솔 오류 없음).
- **아직**: 실제 화면 적용(v1.2 커밋 후), 실제 그림 연결(기획자 그림 대기), 스토어 아이콘·썸네일.

## 기획자 UI 시안 6장 반영 (2026-11-18)
- 시안(`art-src/`의 로비 3장·UI 시트·소환·컬렉션)은 버튼·글자가 박힌 통그림이라 화면으로 그대로 쓰지 않고, **구성과 장식을 코드로 다시 만듦**(`src/ui/kit2.ts`): 짙은 보라 판, 아이콘 타일, 날개 금테 배너(엠블럼), 프로필·재화 머리줄, 드래곤 캐러셀, 원형 바로가기, 돌 제단, 흔들리는 횃불, 진행도 상자 패널.
- 아이콘 22개는 시안 타일에서 바탕을 지워 임시로 떼어 씀(`scripts/cut_ui_icons.py`). 깨끗한 아이콘 묶음이 오면 교체.
- 로비 시안 형식: 날개 배너(단계·난이도·진행도) · 양옆 아이콘 기둥(출석·임무·도감·업적 / 이벤트·상자·카드·목표) · 횃불과 제단 위 출격 드래곤(살짝 떠오르는 움직임) · 드래곤 캐러셀(10종) · 진행도 25/50/100% 상자 · 원형 버튼(단계 지도·연구소) · 아이콘 전투 시작 · 하단 탭(상점·드래곤·전투·장비·소환).
- 시안에서 **빼거나 바꾼 것**: ⚡ 행동력(우리 기획에 없음, 정하면 추가) · 룰렛·현금 패키지(첫 출시 범위 밖) · 파란 슬라임 프로필(참고 게임 아바타와 비슷함 → 출격 드래곤 얼굴) · 받침대 위 파란 수정 탭(참고 게임과 비슷함).
- 개발 메모: Phaser 4.2.1은 한 장면에서 32개가 넘는 파일을 읽으면 나머지가 대기열에서 멈춤 → 게임 설정 `loader.maxParallelDownloads`를 넉넉히(128). 실제 게임에 옮길 때도 같은 설정 필요.

## 상점·드래곤·장비 화면도 시안 형식으로 (2026-11-18)
- 공통: 금색 리본 제목 · 탭 줄(선택 탭 노란 알약) · 짙은 보라 판 · 머리줄(행동력 게이지·타이머 · 골드 · 루비).
- 상점: 큰 소환 배너(드래곤·스킬 상자 + 양옆 드래곤, 빛 움직임) · 1회/10회 루비 · 희귀 3/10·전설 27/90 보장 · 확률 보기 · 장비·골드 상자 카드.
- 드래곤: 초상 타일 4열(등급 점·Lv·별 5칸, 미보유 실루엣·등급명) · 보유 수 · 정렬·필터.
- 장비: 제단 위 출격 드래곤 + 양옆 장착 슬롯 4(빈 칸은 +) · 능력치 줄(공격력·HP·피해 감소) · 탭(장비 목록·강화·합성) · 보유 장비 격자(등급 색 칸 + Lv) · 합성 3→1.
- 소환 탭(하단 오른쪽)은 아직 부품 페이지로 연결(소환 화면은 상점의 상자 배너와 합칠지 정할 것).
