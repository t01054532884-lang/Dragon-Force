## 3. 변신 효과음 공통 규칙

- **길이 1.8~2.2초, mp3, 모노 괜찮음.** 파일 `sfx-boss-transform-<id>.mp3`.
- 구조: **0~0.7초 기가 모이는 소리(점점 높아짐) → 0.7초쯤 "펑" 터짐(그림이 바뀌는 순간) → 0.8~2초 그 보스의 고유 소리(위 표)**.
- 배경 음악 위에서 잘 들리게 보스 처치음(`sfx-boss-die`)과 비슷한 크기. 말소리(대사)는 넣지 않는다 → 한국어·영어 버전 따로 필요 없음.
- 기존 소리와 겹치지 않게: 보스 등장 경고·격노 소리와 다른 느낌으로.

## 4. 게임에서 보이는 방식(코드, AI가 만듦)

체력 50% → 보스 **2초 무적** · 화면 살짝 어두워짐 → 보스가 떨리며 하얗게 빛남(0.7초) → **섬광 + 파동 고리 + 그림 교체 + 효과음 "펑"** → 이름 띠 "○○ — 보스 2페이즈!"(제작자 11/25: "변신!"은 촌스러움) → 대형 스킬이 패턴에 추가. 그림이 없는 보스는 도형 몸 색이 진해지고 커지는 것으로 대신.
