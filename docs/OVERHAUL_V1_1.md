## 2. 그림 8차분 — 전용 스킬 전투 효과 10장
원본 `art-src/batch8-fx/raw-1~10.png`(1254×1254 투명) → `py scripts/process_art_batch8.py` → `public/art/fx/<이름>.webp`(여백 자르기, 512×512, 44~85KB) → `ART_FILES` 연결. 받은 그림이 비스듬한(옆에서 본) 시점이라 쓰는 방법을 맞춤:
- 바닥 불길·독구름: 돌리지 않음(도형 임시 그림일 때만 회전)
- 블루 냉기 장판: 얼음 결정 그림 대신 도형 장판 유지(결정 그림은 폭발 순간에)
- 스톤 바위 파동: 바위 그림 8개가 고리 모양으로 바깥까지 솟아 나감 + 퍼지는 고리, 방어막은 빛 보호막 그림을 흙빛으로
- 아케인 마력탄: 날아가는 방향으로 회전, 워터 해일: 진행 방향으로 뒤집어 앞으로 밀려감, 옐로 연쇄: 구간마다 번개 그림 + 기존 선
- 확인: 브라우저에서 윈드 칼날(512 그림) 전투 화면.

## 3. 결정 필요 — v1.1과 앞선 지시가 다른 곳(코드는 아직 v1.0 그대로)
| 항목 | v1.0 기획서 + 그래프 메모(제작자) | v1.1 | 지금 구현 |
|---|---|---|---|
| 엘리트 2마리 | **2단계부터**("엘리트 2마리는 2단계부터") | 5단계 첫 등장, 13–14·18–19 | v1.0 |
| 보스 2마리 | **5단계부터**(5·10·14·17·19·20) | 10·15·20 | v1.0 |
| 시작 카드 | 3번 고름(3장 × 3) | "카드 3장 중 1장" | v1.0(3번) |
| 단계 기믹 | 보스 가속·범위·위험 지대·광폭화 등 17종 | 출현 간격 단축(3–4)·밀도 소폭 증가(6–7)·엘리트 직후 일반 웨이브(8–9, 13–14)·웨이브 간격 단축(16–17) | v1.0 |
| 권장 전투력 | 표(2단계씩 같은 값) | 선형 1.50 + 0.50 × (단계−1)/19 | v1.0 표(차이 최대 0.03배) |

→ v1.1로 바꿀지, v1.0을 유지할지(또는 섞을지) 정해 주면 `hardStages.ts` 데이터만 바꾸면 된다(시작 카드 횟수도 설정값 `startingSkillChoices`).

## 4. 가격 인상의 영향 — **제작자 확인: 괜찮음(이벤트로 루비를 많이 주므로), 250/2,200 확정(2026-11-21)**
- 출시 기념 1,000루비 + 첫 업적(약 1,050)으로 이전엔 10회를 바로 1번 열 수 있었는데, 2,200이면 **첫날 10회가 안 될 수 있음**(단품 4~8번은 가능).
- 정수 시뮬레이션(규칙 그대로): 10종 모두 보유 중앙값 10회 × 11번 → 이전 약 14,850 → **약 24,200루비**.
- 루비 상품 이름 `ruby_1350`(“11,000원 = 10회 소환 1,350루비”, 미등록 초안)은 새 가격과 안 맞음 → App Store Connect 등록 전에 상품 구성 확정 필요(`docs/MONETIZATION_PLAN.md`).
