# 그림·소리 요청서 5 — 종합 개선 기획서 v1.0 작업용 (2026-11-21)

종합 개선 기획서 v1.0(2배속 제외) 작업에 필요한 그림과 소리. **모두 없어도 개발은 진행된다** — 지금은 코드로 그린 도형·합성음으로 대신하고, 파일이 오면 이름만 맞춰 넣으면 자동으로 바뀐다.
이미 요청한 것(요청서 4의 전용 액티브 아이콘 `sig-<드래곤>.png` 10장, 특수 스킬 15장, HANDOFF 3절 보상 카드 프레임)은 **아직 안 왔으면 그대로 필요**하다 — 아래 "다시 확인"에 적었다.

## 공통 규칙
- 그림: **1024×1024, 투명 배경**(안 되면 순수 초록 #00FF00), 그림은 캔버스 가운데, 글자·숫자 없음. 원본은 `art-src/`에 아래 파일 이름 그대로 → AI가 가공해 `public/art/`에 넣는다.
- 화풍 기준 첨부: `public/art/portrait-red.webp` + `public/art/skill/skill-meteor.webp`.
- 소리: 상업 이용 가능한 출처(직접 생성 포함), 모노 44.1kHz `.mp3`, 앞뒤 무음 자르기. 넣을 곳 `public/sfx/<이름>.mp3`. 출처는 `docs/SOUND.md`에 기록.
