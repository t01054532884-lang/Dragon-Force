# 그림·소리 요청서 5 — 종합 개선 기획서 v1.0 작업용 (2026-11-21)

종합 개선 기획서 v1.0(2배속 제외) 작업에 필요한 그림과 소리. **모두 없어도 개발은 진행된다** — 지금은 코드로 그린 도형·합성음으로 대신하고, 파일이 오면 이름만 맞춰 넣으면 자동으로 바뀐다.
이미 요청한 것(요청서 4의 전용 액티브 아이콘 `sig-<드래곤>.png` 10장, 특수 스킬 15장, HANDOFF 3절 보상 카드 프레임)은 **아직 안 왔으면 그대로 필요**하다 — 아래 "다시 확인"에 적었다.

## 공통 규칙
- 그림: **1024×1024, 투명 배경**(안 되면 순수 초록 #00FF00), 그림은 캔버스 가운데, 글자·숫자 없음. 원본은 `art-src/`에 아래 파일 이름 그대로 → AI가 가공해 `public/art/`에 넣는다.
- 화풍 기준 첨부: `public/art/portrait-red.webp` + `public/art/skill/skill-meteor.webp`.
- 소리: 상업 이용 가능한 출처(직접 생성 포함), 모노 44.1kHz `.mp3`, 앞뒤 무음 자르기. 넣을 곳 `public/sfx/<이름>.mp3`. 출처는 `docs/SOUND.md`에 기록.

## A. 그림

### 1순위 — 전용 스킬 전투 효과 (P0 "드래곤마다 다른 전용 효과")
전투 중 실제로 화면에 뜨는 효과 그림. **반투명·밝은 색 위주**(적 공격 예고의 붉은 바닥을 가리지 않게 빨강 단색은 피함). 512×512 권장.

| 파일 | 드래곤 · 쓰는 곳 | 설명 |
|---|---|---|
| `fx-wind-blade.png` | 윈드 · 폭풍 질주 회전 칼날 | 초승달 모양 청록·흰 바람 칼날 한 개(옆에서 본 게 아니라 위에서 본 납작한 칼날), 끝이 가늘게 흩어짐 |
| `fx-fire-ground.png` | 레드 · 폭발 뒤 남는 불길 | 위에서 본 둥근 바닥 불길(가운데 밝은 노랑 → 바깥 주황), 가장자리 부드럽게 투명 |
| `fx-ice-crystal.png` | 블루 · 얼음 결정 폭발 | 위에서 본 별 모양으로 솟은 하늘색 얼음 결정 무리 |
| `fx-lightning-arc.png` | 옐로 · 연쇄 번개 줄기 | 가로로 긴(1024×256도 됨) 노란·보라 번개 줄기 한 가닥 |
| `fx-poison-cloud.png` | 그린 · 독구름 | 위에서 본 둥근 초록 독안개와 보라 거품, 가장자리 투명 |
| `fx-rock-wave.png` | 스톤 · 바위 파동 | 위에서 본 둥근 고리 모양으로 갈라져 솟은 바위 조각들(가운데 비움) |
| `fx-light-shield.png` | 화이트 · 빛의 보호막 | 위에서 본 둥근 금빛 반투명 보호막과 깃털 무늬 |
| `fx-shadow-orb.png` | 블랙 · 암흑 투사체·분신 | 보라·검정 암흑 구체(꼬리 없이 둥근 것) |
| `fx-wave.png` | 워터 · 해일 | 위에서 본 앞으로 밀려가는 물결 띠(가로로 긴 모양) |
| `fx-arcane-bolt.png` | 아케인 · 마력탄 | 분홍·보라 별빛이 섞인 작은 마력탄 |
