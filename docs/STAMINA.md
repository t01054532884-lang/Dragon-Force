# 행동력 · 선물함 (기획 v1.4, 2026-11-18)

## 기획(제작자)
- 최대 40, 30분마다 1 회복(0→40 20시간), 40이면 타이머 정지, 39 이하가 되면 시작, 앱을 꺼도 경과 시간만큼 회복
- 메인 상단에 현재 행동력과 다음 회복까지 남은 시간
- 스테이지·난이도별 **최초 클리어** 때 행동력 20을 **선물함**으로(바로 더하지 않음), 반복 클리어는 없음, 지급 기록 저장(중복 없음)
- 선물함: "행동력 충전 선물 ×20", 개별 수령, 수령 후 40을 넘으면 받지 않고 보관, 선물함의 행동력은 상한에 안 들어감, 앱을 꺼도 유지
- 입장 비용 임시 5(최종은 밸런스로)
