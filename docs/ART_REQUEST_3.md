## 3순위 — 전투 화면 (지금은 도형 임시 그림)

### 왜 따로 필요한가
전투는 **위에서 내려다보는 화면**이고, 캐릭터가 움직이는 방향으로 **그림을 통째로 돌린다**. 초상(3/4 앞모습)을 돌리면 옆으로 누운 그림이 된다 → **바로 위에서 본, 머리가 한쪽을 향한 그림**이 필요. 화면에서 드래곤 80~100px, 일반 적 50~60px로 작게 보이니 **실루엣은 또렷하게, 자잘한 디테일은 줄여서**.

```
첨부한 그림과 같은 부드러운 채색으로, 탑다운 게임용 바닥 텍스처. 바로 위에서 본 잿빛 돌바닥: 둥글둥글한 회색 돌판, 틈새에 재와 아주 작은 붉은 불씨, 군데군데 마른 이끼. 네 변을 이어 붙여도 이음새가 보이지 않는 반복 무늬(seamless tileable). 어둡고 차분하게, 큰 물체·그림자·조명 없음, 글자 없음.
```
