# 개발 4단계 — 엘리트·보스·클리어 (1단계 잿빛 숲)

제작자 기획(2026-11-17): 일반 전투 → 엘리트 1 → 일반 전투 → 엘리트 2 → 보스 → 클리어, 8분.
1~10단계 마수 지역 / 11~20단계 인간 왕국, 5·10·15·20단계 최종보스, 난이도 공식, 화면 표시, 상태 구조, 완료 기준.
MVP는 **1단계 잿빛 숲**만: 일반 마수 2종 + 엘리트 2종 + 일반 보스 1종 + 엘리트 흡수 + 클리어·실패.

## 검토에서 나온 것과 확정
| # | AI가 찾은 것 | 확정 |
|---|---|---|
| 1 | "8분 격노 확정"과 기획서 "8분 시간 초과 실패"가 충돌 | **7:30 격노 → 8:00 실패**. 격노는 보스 체력을 늘리지 않고 피해 ×1.5, 이동·패턴 속도 ×1.3 (거의 잡은 보스가 회복해서 억울해지지 않게) |
| 2 | 철갑어미 "벽에 부딪힐 때까지 돌진"인데 맵에 벽이 없음 | **원형 투기장**(반지름 22m = 1100px). 벽 충돌 → 충격파 |
| 3 | 엘리트 보상 "보스 흡수 강화 1개 제거"는 이중 계산(처치한 엘리트는 애초에 흡수 안 됨) | "처치하면 흡수 대상에서 빠진다"로 구현 |
| 4 | 보스 돌진 몸통 피해 45%가 "최대 HP 35% 상한"을 넘음 | 엘리트·보스 한 방 피해를 코드에서 최대 HP 35%로 제한 |
| 5 | 1단계 보스 회색갈기 우두머리 패턴이 기획서에 없음 | AI 1차안: 돌진 / 그림자 늑대 4마리 소환 / 전방 부채꼴 할퀴기, 60% 이후 3연속 돌진·패턴 간격 0.75배 |
| 6 | "실패 시 영구 재화는 기획된 비율만"인데 비율 없음 | **50%** |
| 7 | 엘리트 18~22초·보스 55~75초 목표는 그때 DPS를 알아야 맞출 수 있음 | 결과 화면에 실제 처치 시간 기록 → 플레이 테스트로 체력 조정 |

## 1단계 잿빛 숲 구성
| 시간 | 진행 | 구현 |
|---|---|---|
| 0:00 | 그림자 늑대(무리 2~3마리, 양옆으로 돌아 포위) | 1분부터 철갑 멧돼지(예고선 0.8초 → 직선 돌진 → 0.9초 기절) 섞임 |
| 1:35 / 1:40 | 엘리트 1 경고 / 월광송곳니 | 초승달 3연속 돌진(돌진마다 0.6~0.8초 휘는 예고선) → 기절. 체력 520 |
| 3:35 / 3:40 | 엘리트 2 경고 / 철갑어미 | 벽까지 돌진 → 부딪힌 자리 0.8초 예고 → 충격파 26 → 1.4초 기절. 체력 850 × 1.15 = 977 |
| 5:40 | 보스 경고: 화면 어두워짐, 일반 적 50% | |
| 5:50 | 회색갈기 우두머리, 일반 적 자연 생성 중단 | 체력 3000 × 1.3 = 3900, 살아 있는 엘리트 흡수(1: HP +10%, 2: 피해 +10%) |
| 7:30 | 격노 | 피해 ×1.5, 속도 ×1.3, 체력 그대로 |
| 8:00 | 시간 초과 실패 | 그 판 골드 50% 유지 |

엘리트 공통: 둔화 효과 60% 감소, 밀치기 30%, 살아 있는 동안 일반 적 70%, 처치 보상(대형 경험치 결정 25 + 최대 HP 12% 회복) 한 번만.
클리어 연출(기획서 6장 순서): 0.35배 슬로모션 0.4초 → 위험 지역 제거 → 남은 적 빛으로 소멸 → 경험치 자동 회수 → 무적 → 2.5초 연출 + 황금 포털 → 결과 화면(보상·전투 기록·시드) → 다음 단계/재도전. 클리어하면 다음 단계 해금을 브라우저에 저장.

## 완료 기준 확인 (기획서 19장, 2026-11-17, 별도 탭에서 시간을 건너뛰며 확인)
| 기준 | 결과 |
|---|---|
| 엘리트가 정확히 1:40과 3:40에 등장 | `elite:spawn` 100,013ms / 220,000ms (1프레임 이내) |
| 엘리트 총 2마리 초과 안 함 | 동시 생존 최대 1~2, 최대 2 제한 코드 |
| 처치 보상 한 번만 | 처치 후 같은 엘리트로 보상 함수를 다시 불러도 `false`, 대형 결정 1개 |
| 살아 있는 엘리트가 보스 등장 시 제거·강화로 변환 | 엘리트 2 생존 → 사라짐, 슬롯 붉은색, 보스 피해 ×1.1 |
| 보스 5:50 등장 | `boss:spawn` 350,001ms, 경고 340,000ms |
| 보스 등장 후 일반 자연 생성 중단 | 5초 동안 새로 생긴 적 0(소환 늑대 제외), 생성량 0 |
| 페이즈 전환 체력 기준 한 번만 | 60% 아래로 두 번 때려도 `boss:phase-change` 1회 |
| 보스 처치 즉시 적 공격·피해 판정 중단 | 처치 순간 위험 지역 0개, 무적, 체력 200 그대로 |
| 남은 경험치 자동 회수 | 결정 14개 → 1.5초 뒤 0개 |
| 클리어 후 다음 단계 해금 | 저장값 `2` |
| 8분까지 보스 생존하면 실패 | `stage:fail` 480,014ms, 사유 timeout |
| 재도전 시 정상 초기화 | 시간·레벨·체력·처치·골드·엘리트 슬롯·보스·이벤트 기록·기본공격 Lv.1·물리 속도 모두 처음 값 |
| 같은 난수 시드로 재현 | 시드 777로 두 번 시작 → 처음 생성 20마리의 종류·위치 완전히 같음(시드 12345와는 다름). 단, 생성 위치는 플레이어와의 거리도 보므로 "같은 시드 + 같은 이동"일 때 같다 |

**아직 안 한 것**: 처음부터 8분을 실제 손으로 해 보는 플레이 테스트. 엘리트·보스 목표 처치 시간(18~22초 / 22~28초 / 55~75초)에 맞는지는 결과 화면의 기록으로 확인해 체력을 조정해야 한다.
