- 룰렛 1회 루비 기대값 = 10×25% + 20×25% + 30×20% + 40×12% + 50×8% = **22.3** → 30회 **669** ✅

## 구현
| 항목 | 결과 |
|---|---|
| 장비 | 고정값 폐기. 무기 = 공격력 %, 갑옷 = HP %(일반 4 · 희귀 7 · 영웅 11 · 전설 16), Lv.10 = 1.45배. 드래곤 기본값 × (1 + 연구소 + 레벨 + 승급 + 장비) — 같은 능력치 보너스는 합산. 장비 HP는 35% 한 방 상한 기준에서 뺀다. 소수 둘째 자리 반올림(7 × 1.45 = 10.15%가 잘리지 않게) |
| 전용 액티브 | "총 5배" 폐기. 쓰는 순간의 **현재 기본 공격 DPS** 기준 고정 피해: 광역(레드·블루·옐로·블랙·워터) 대상당 DPS×3초·총합 최대 DPS×12초, 단일(아케인) DPS×4초, 지속(그린) 5초간 대상당 DPS×3초, 회복(화이트) 최대 HP 15%, 방어(스톤) 4초 −25%, 이동 강화(윈드) 5초 +25% + 약한 회오리. 공격력·특성·치명타·분노 같은 보너스를 다시 곱하지 않음. 재사용 60초 유지 |
| 겨울 축제 | KST 2026-12-01 00:00 ~ 2027-01-01 00:00(끝 제외). 로비 "겨울 축제" 버튼(받을 것이 있으면 빨간 점), 이벤트 화면(룰렛·출석 탭), 전투 결과에 룰렛 진행 표시 |
| 행운 룰렛 | 정상 종료(클리어·사망·시간 초과) + 60초 이상 전투 5판마다 1회. 포기 제외, 같은 전투(runId)는 한 번만. 확률은 설정 표 그대로 화면에 표시. 누적 5·10·20·30회 보상은 도달하는 회차에 자동으로 한 번 지급 |
| 정수 확정 상자 | 그 등급 드래곤 중 하나(레드 제외, 균등). 보유 중이면 중복 정수 → 조각(희귀 30·영웅 50). **소환 천장 카운터에 영향 없음** |
| 크리스마스 출석 | 하루 1회(KST 자정 갱신), n번째 출석은 표의 n mod 7번째(100~700). 빠진 날이 있어도 누적은 이어진다 |
| 난수 | 이벤트마다 저장에 시드를 두고 "시드 + 회차"로 결과를 정한다(mulberry32). 같은 회차를 다시 시도해도 결과가 같다 |
| 저장 | `events[이벤트 id]` = 시드·인정 판수·돌린 횟수·받은 누적 보상·출석일. 이벤트가 끝나도 받은 루비·정수와 기록은 남는다. 이벤트 기록이 없는 예전 저장도 그대로 열림 |
| 결제 | 첫 출시 제외 그대로(v1.2의 `Purchases.ts` 구조만) |
| 개발용 | `?dev=1&now=2026-12-05`(또는 `2026-12-05T23:59:30`)로 게임 안 날짜를 바꿔 이벤트·미션 시험 |
