### 2. 기존 기능에서 바뀐 것
- 전용 스킬 수치(2026-11-20 값)는 그대로, 거기에 속성별 추가 효과를 얹음: 레드 남는 불길(0.5초마다 DPS × 0.3), 블루 냉기 장판(45% 둔화), 옐로 연쇄 3갈래(대상당 광역 피해의 60%), 화이트 보호막 지속 4초 → 성장 시 +1초, 블랙·워터 추가 빔/해일은 첫 번째의 절반 피해, 스톤 두·세 번째 파동은 절반.
- 그린 독구름·윈드 회오리 지속 계산은 같고, 윈드 회오리 타격 간격 0.5초(원문 0.4~0.6초).
- 미션 보상 받기는 같은 규칙(기간당 1회)을 그대로 거침 — 모두 받기도 한 미션씩 같은 함수.

### 3. 드래곤 정수 확률 확인(원문 4.1) — **수치는 바꾸지 않음, 결정 필요**
현재 규칙(원문 6장 + 제작자 임시): 1차 추첨 카드 40 · 조각 25 · **정수 15** · 특수 스킬 조각 20%, 정수 희귀도 70/22/7/1, **10회째 희귀 이상 정수 보장**, 90회째 전설 보장. 미보유 드래곤 해금 = 정수 1개(또는 조각 40/60/100/160), 중복 정수 = 조각 20/30/50/80. 레드 제외 9종.

시뮬레이션(실제 `openBox` 규칙, 2만 명, `npx vite-node scripts/sim_summon.ts`):

| 항목 | 값 |
|---|---|
| 첫 10회 정수 개수 평균 | **2.07개** |
| 첫 10회 분포 | 1개 32.6% · 2개 38.5% · **3개 20.6%** · 4개 6.7% · 5개 이상 1.6% |
| 10회 × 1 뒤 보유 드래곤(레드 포함) | 2.91종 |
| 10회 × 3 / × 5 / × 10 뒤 | 5.50 / 7.01 / 9.29종 |
| 10종 모두 보유까지 | 10회 묶음 중앙값 11번(약 14,850루비) · 90%는 22번 |

- 플레이에서 본 "10회에 정수 3개"는 5번에 1번꼴(20.6%)로 정상 범위. 10회째 보장이 있어 최소 1개는 항상 나온다.
- 신규 계정은 출시 기념 1,000 + 업적 루비로 10회를 한 번 돌릴 수 있고, 그러면 평균 약 2종이 바로 해금된다.
- **선택안(제작자 결정)**: ① 그대로(초반 해금이 빠른 대신 희소성 낮음) ② 정수 15 → 10%(10회 평균 약 1.6개 예상, 보장은 유지) ③ 확률은 유지하고 10회 보장을 "희귀 이상 정수"에서 "정수 또는 조각 20개"로 바꿔 미보유 해금 속도만 낮춤 ④ 누적 50회 선택형 정수 추가(원문 4.2-4). 결정되면 `src/data/economy.ts` `DRAGON_BOX` 숫자와 확률 안내 화면만 바꾸고 시뮬레이션을 다시 돌린다.
