# 그림 요청서 4 — UI 작업에서 생긴 필요 그림 (2026-11-20)

8단계 C(상점·장비·드래곤 공통 UI)를 만들며 **아직 이모지·기호로 대신하고 있는 곳**만 모았다. 이미 받은 그림(`docs/HANDOFF.md` 3절: 재화·상자·초상 10·탑다운 10·스킬 15·장비 16·UI 아이콘 등)과 HANDOFF 3절 "아직 필요한 것" 표(앱 아이콘·스크린샷·전투 효과·빛 조각·적·바닥·보상 카드 프레임·로비 분리판·날갯짓)는 여기서 다시 요청하지 않는다.

## 넣는 곳 · 가공 방법
1. 원본을 **`art-src/`** 에 아래 **파일 이름 그대로** 넣는다(`.png`, 1024×1024 권장). GPT 기본 이름이어도 되지만 그러면 AI가 그림을 보고 이름을 붙인다.
2. AI가 `python scripts/process_art_batch6.py` 실행 → `public/art/special|sig|lab|ui/`에 256×256 투명 WebP. 일부만 와도 된다(없는 것은 건너뛰고 목록을 알려 줌).
3. AI가 `src/ui/art.ts`의 `ART_FILES`에 연결하고, 화면의 이모지 자리를 그림으로 바꾼다(그림이 없으면 지금처럼 이모지).

## 공통 규칙
- **1024×1024, 투명 배경**(투명 옵션이 없으면 순수 초록 #00FF00 배경), 그림은 **캔버스 가운데**, 글자·숫자 없음.
- **첨부 2장**: 화풍 기준 `public/art/portrait-red.webp`(아틀라스 레드, 원본이 있으면 `art-src/style-anchor-red.png`) + 배지 틀 기준으로 이미 받은 스킬 아이콘 `public/art/skill/skill-meteor.webp`(저장소에 있음).
- `art-src/`는 git에 올리지 않는 폴더라 새 컴퓨터에는 없을 수 있다 — 없으면 저장소 맨 위에 `art-src` 폴더를 새로 만들고 넣는다.
- 아래 "GPT에 붙일 한 줄"은 그대로 복사해서 쓰면 된다(화풍 문구 포함).
