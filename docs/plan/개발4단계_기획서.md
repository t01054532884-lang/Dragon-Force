# 개발 4단계: 엘리트·보스·클리어 시스템 (제작자 기획 원문, 2026-11-17)

> 제작자가 대화로 준 원문을 그대로 옮김. 검토에서 바뀐 점(격노 후 실패, 원형 투기장, 실패 골드 50%, 흡수 보상 해석, 35% 상한, 보스 패턴 1차안)은 `docs/STAGE.md` 참고.
> 콘셉트 이미지 3장(마수 지역 / 인간 왕국 / 엘리트·보스·클리어 흐름)은 방향 참고용이라 저장소에 넣지 않았다.

## 1. 핵심 방향

한 스테이지는 8분이며 다음 순서로 진행한다.

> 일반 전투 → 엘리트 1 → 일반 전투 → 엘리트 2 → 보스 → 클리어

모든 스테이지에 엘리트가 총 2마리 등장한다. 두 엘리트는 동시에 생성하지 않고 일정한 시간 차이를 두고 생성한다.

5·10·15·20단계에서는 일반 보스 대신 해당 구역을 마무리하는 최종보스가 등장한다.

### 세력 구분

- 1~10단계: 마수 지역
- 11~20단계: 인간 왕국
- 5단계: 마수 지역 중간 최종보스
- 10단계: 마수 지역 최종보스
- 15단계: 인간 왕국 중간 최종보스
- 20단계: 전체 캠페인 최종보스

1~10단계와 11~20단계의 차이는 외형만 바꾸는 것이 아니다.

마수는 돌진, 포위, 독지대, 비행, 땅굴처럼 본능적이고 불규칙한 공격을 사용한다. 인간은 방패벽, 궁수 사격, 마법진, 측면 공격, 지휘관 버프처럼 조직적인 전술을 사용한다.

## 2. 이야기 연결

### 1~10단계: 오염된 마수 지역

레드 드래곤은 마수들이 갑자기 흉폭해진 원인을 조사하며 마수 영역을 통과한다. 마수들은 원래부터 악한 존재가 아니라, 인간 왕국에서 흘러나온 '검은 왕관의 파편'에 오염된 상태다.

10단계 최종보스를 쓰러뜨리면 보스의 몸에서 인간 왕국의 문장이 새겨진 마력 창과 실험용 봉인이 발견된다.

### 11~20단계: 인간 왕국

인간 왕국은 드래곤이 마수 사태를 일으켰다고 선전하며 군대를 보낸다. 실제로는 왕이 마수의 힘과 드래곤의 심장을 이용해 영원한 힘을 얻으려 하고 있다.

20단계에서 레드 드래곤은 포획한 드래곤의 심장을 사용하는 인간 왕과 싸운다.

이 구조를 사용하면 마수와 인간 구간이 단절되지 않고 하나의 이야기로 연결된다.

## 3. 스테이지 시간표

| 시간 | 진행 |
|---|---|
| 0:00 | 스테이지 시작, 일반 적 생성 |
| 1:35 | 엘리트 1 경고 표시 |
| 1:40 | 엘리트 1 생성 |
| 3:35 | 엘리트 2 경고 표시 |
| 3:40 | 엘리트 2 생성 |
| 5:40 | 보스 경고 및 일반 적 생성 감소 |
| 5:50 | 보스 생성 |
| 8:00 | 보스가 생존해 있으면 시간 초과 실패 |

### 엘리트 전투 중 일반 적

- 엘리트가 생존한 동안 일반 적 생성량을 기본값의 70%로 낮춘다.
- 엘리트 처치 시 일반 적 생성량을 100%로 복구한다.
- 첫 번째 엘리트를 처치하지 못해도 3분 40초에 두 번째 엘리트가 등장한다.
- 따라서 플레이어가 화력이 부족하면 두 엘리트가 잠시 겹칠 수 있다.
- 화면에 살아 있을 수 있는 엘리트는 최대 2마리다.

### 보스 등장 시 엘리트가 살아 있는 경우

보스와 엘리트가 모두 남아 전투가 불가능해지는 상황을 막기 위해, 보스 등장 시 생존 엘리트는 사라지고 보스에게 흡수된다.

- 엘리트 1 생존: 보스 최대 HP 10% 증가
- 엘리트 2 생존: 보스 피해 10% 증가
- 두 엘리트 모두 생존: 두 효과 모두 적용
- 흡수된 엘리트는 처치 보상을 주지 않는다.

엘리트를 놓쳤다는 사실이 보스전에 영향을 주지만, 플레이 자체가 막히지는 않게 한다.

## 4. 엘리트 시스템

### 공통 규칙

- 일반 적보다 약 2.5배 큰 실루엣
- 화면 상단에 전용 체력바 표시
- 등장 5초 전 경고 아이콘과 바닥 표시
- 군중제어 저항 60%
- 완전 빙결 대신 빙결 지속시간 50% 감소
- 밀치기 거리는 일반 적의 30%
- 엘리트끼리 동일한 위치에 겹치지 않도록 충돌 반경 적용

### 처치 보상

각 엘리트는 다음 보상을 확정 지급한다.

- 대형 경험치 결정 1개
- 최대 HP의 12% 회복
- 보스 흡수 강화 1개 제거

MVP에서는 엘리트 전용 장비나 별도 선택 화면을 넣지 않는다. 보상 UI가 추가되면 전투 흐름이 끊기기 때문이다.

### 목표 처치 시간

- 엘리트 1: 18~22초
- 엘리트 2: 22~28초
- 35초 이상 걸리면 해당 스테이지의 체력이나 방어력을 하향 검토
- 10초 안에 처치되면 체력 또는 패턴 생존성을 상향 검토

## 5. 보스 시스템

### 일반 스테이지 보스

대상 단계: 1~4, 6~9, 11~14, 16~19

- 보스 등장 시 일반 적 자연 생성 중단
- 보스가 직접 소환하는 적만 등장 가능
- 화면 상단에 대형 체력바 표시
- 체력바에 60% 패턴 변화 지점 표시
- 목표 처치 시간 55~75초
- 가장 강한 단일 공격도 동일 성장도 플레이어 최대 HP의 35%를 넘기지 않음
- 큰 공격은 최소 0.8초 전에 바닥 범위로 예고

### 5단계 단위 최종보스

대상 단계: 5, 10, 15, 20

- 70%와 35% 체력에 페이즈 전환
- 페이즈 전환 중 1초간 피해 면역
- 전환 순간 기존 적 투사체 제거
- 목표 처치 시간 90~120초
- 가장 강한 공격은 최대 HP의 45% 이하
- 즉사 공격은 사용하지 않음
- 최종보스 전용 등장 연출 2~3초
- 첫 클리어 시 다음 구역 해금

## 6. 보스 처치와 클리어 처리

보스 HP가 0이 되면 다음 순서로 처리한다.

1. 보스 사망 이벤트 발생
2. 게임 속도 0.35배로 0.4초간 감소
3. 적 투사체와 위험 지역 제거
4. 남은 일반 적은 빛으로 소멸
5. 맵에 남은 경험치와 재화를 자동 회수
6. 플레이어에게 무적 적용
7. 2.5초 동안 클리어 연출
8. 황금색 탈출 포털 생성
9. 결과 화면에서 보상과 전투 기록 표시
10. 다음 단계 또는 재도전 선택

### 실패 조건

- 플레이어 HP가 0
- 8분까지 보스를 처치하지 못함

실패 시 획득한 영구 재화는 기획된 비율만 유지하고, 전투 레벨과 스킬은 초기화한다.

## 9. 마수 최종보스

### 5단계: 붉은뿔 마수왕 베르칸

외형: 사자와 들소가 섞인 거대한 마수, 붉게 달아오른 뿔, 몸에 검은 왕관 파편이 박혀 있음

- 페이즈 1: 전방 뿔 돌진, 원형 발구르기 충격파, 그림자 늑대 4마리 소환
- 페이즈 2(HP 70%): 뿔이 붉게 발광, 돌진이 벽에 충돌하면 세 방향 충격파 발생, 공격 후 짧은 약점 시간 제공
- 페이즈 3(HP 35%): 중앙으로 이동해 연속 발구르기, 안전지대가 시계 방향으로 회전, 마지막 돌진 후 2초간 그로기

### 10단계: 천년독룡 오로바스

외형: 폐허의 문을 감고 있는 거대한 뱀형 마수, 몸 일부가 돌처럼 굳어 있음, 독안개와 석화 시선을 사용

- 페이즈 1: 부채꼴 독액, 꼬리 휩쓸기, 독 웅덩이 생성
- 페이즈 2(HP 70%): 허물을 벗고 이동속도 증가, 직선 석화 시선, 피격 시 완전 석화 대신 1.5초간 이동속도 70% 감소
- 페이즈 3(HP 35%): 맵 외곽을 몸으로 둘러 전투 공간 축소, 독안개가 바깥에서 안쪽으로 접근, 머리를 내려찍은 뒤 약점 노출

처치 후 인간 왕국의 문장이 새겨진 창이 몸에서 발견된다.

## 10. 인간 세력: 11~20단계

### 인간 일반 병력

| 적 | 역할 | 공격 |
|---|---|---|
| 검병 | 기본 근접 | 플레이어 추적 후 베기 |
| 방패기사 | 전열 방어 | 정면 피해 감소와 방패 밀치기 |
| 장궁병 | 원거리 | 예고선 후 화살 사격 |
| 전투마법사 | 지역 통제 | 원형 마법진과 느린 마력탄 |
| 그림자 도적 | 기습 | 잠깐 은신 후 측면 돌진 |
| 군기병 | 지원 | 주변 인간 병력 공격력 강화 |

인간은 개별적으로 강하기보다 진형을 통해 강해진다.

- 방패기사는 궁수와 마법사를 보호한다.
- 장궁병은 방패기사 뒤에서 사격한다.
- 도적은 플레이어가 방패벽을 상대하는 동안 측면을 공격한다.
- 마법사는 플레이어의 이동 경로를 제한한다.
- 군기병을 먼저 처치하면 주변 병력의 버프가 사라진다.

## 13. 인간 최종보스

### 15단계: 대장군 발테르

- 페이즈 1: 방패기사 4명이 대장군 앞에 방패벽 형성, 대장군은 뒤에서 창을 던지고 돌진 명령 사용, 방패기사를 처치해야 대장군에게 정상 피해 가능
- 페이즈 2(HP 70%): 방패를 버리고 대형 도끼창 사용, 넓은 부채꼴 베기, 지면을 가르는 직선 충격파
- 페이즈 3(HP 35%): 군기를 땅에 꽂아 공격속도 증가, 군기를 파괴하면 버프 해제, 군기 파괴 후 3초간 그로기

### 20단계: 용사냥왕 아스테리온

왕은 포획한 드래곤의 심장으로 무기와 갑옷을 강화한 인간이다. 완전히 괴물로 변신시키지 않고, 끝까지 인간의 전술과 욕망을 보여준다.

- 페이즈 1(왕의 군대): 방패기사와 궁수 진형 소환, 왕은 후방에서 도끼창과 명령 스킬 사용, 지휘 깃발을 파괴하면 병력 강화 해제
- 페이즈 2(HP 70%, 드래곤 심장 해방): 갑옷에서 화염과 번개가 분출, 플레이어의 화염탄과 비슷한 추적탄 사용, 플레이어에게 자신의 힘을 빼앗아 사용한다는 인상 제공
- 페이즈 3(HP 35%, 무너지는 왕좌): 왕좌 광장 외곽이 붕괴하며 전투 공간 축소, 도끼창 투척·추적탄·직선 돌진을 조합, 마지막 공격 후 드래곤 심장이 노출되며 4초간 최종 약점 상태

처치 후 왕의 갑옷은 무너지지만 드래곤 심장은 파괴되지 않는다. 이후 캠페인이나 무한 모드로 연결할 수 있다.

## 14. 난이도 증가 공식

스테이지 번호를 `S`라고 한다.

```text
적 HP 배율 = 1.12^(S - 1)
적 피해 배율 = 1.075^(S - 1)
생성 속도 배율 = min(2.0, 1 + 0.055 × (S - 1))
```

```text
엘리트 1 HP = 엘리트 기본 HP × 스테이지 HP 배율
엘리트 2 HP = 엘리트 기본 HP × 스테이지 HP 배율 × 1.15
일반 보스 HP = 보스 기본 HP × 스테이지 HP 배율 × 1.30
5단계 최종보스 HP = 최종보스 기본 HP × 스테이지 HP 배율 × 1.70
10·15단계 최종보스 HP = 최종보스 기본 HP × 스테이지 HP 배율 × 1.80
20단계 최종보스 HP = 최종보스 기본 HP × 스테이지 HP 배율 × 2.00
```

공식값을 그대로 출시값으로 확정하지 않는다. 다음 실측값을 우선한다: 엘리트 목표 처치 시간, 보스 목표 처치 시간, 보스전 진입 시 평균 플레이어 HP, 엘리트 미처치율, 시간 초과 실패율, 공격 원천별 DPS.

## 15. 화면 표시

- 엘리트 UI: 화면 상단 보스바보다 작은 전용 체력바, 엘리트 1과 2를 나타내는 마름모 슬롯 2개, 처치 시 슬롯이 녹색, 보스에게 흡수되면 붉은색, 보스 등장 시 붉은 슬롯 수만큼 강화 효과 표시
- 보스 UI: 화면 상단 전체 너비 체력바, 페이즈 전환 지점 표시, 보스 이름 아래 현재 강화 표시(예: `잔존 엘리트: HP 강화`), 최종보스는 체력바 테두리를 금색 또는 붉은색으로 구분
- 경고 표시: 엘리트 등장은 화면 가장자리에서 해당 방향 강조, 보스 등장은 화면 어두워짐과 경고음, 위험 공격은 붉은색 또는 보라색 바닥 예고, 회복·안전 효과는 녹색 또는 금색

## 17. 스테이지 상태 구조

```text
INTRO → WAVE_1 → ELITE_1 → WAVE_2 → ELITE_2 → BOSS_WARNING → BOSS → CLEAR 또는 FAIL
```

엘리트가 생성되더라도 시간 타이머는 멈추지 않는다. 상태 이름은 연출과 UI 상태를 의미하며, 실제 일반 적 생성은 각 상태의 설정에 따라 계속될 수 있다.

필수 이벤트: stage:start, elite:warning, elite:spawn, elite:defeated, boss:warning, boss:absorb-elites, boss:spawn, boss:phase-change, boss:defeated, stage:clear, stage:fail

## 18. 개발 순서

1. 스테이지 상태 머신: 8분 타이머, 엘리트 생성 시간, 보스 생성 시간, 클리어와 실패 전환
2. 엘리트 공통 시스템: 엘리트 체력바, 군중제어 저항, 처치 보상, 미처치 엘리트 흡수, 엘리트 최대 2마리 제한
3. 보스 공통 시스템: 보스 체력바, 페이즈 전환, 패턴 타이머, 소환 패턴, 보스 사망 이벤트
4. 클리어 처리: 투사체 제거, 남은 적 정리, 경험치 자동 회수, 무적 처리, 클리어 화면, 다음 단계 해금
5. 콘텐츠 확장: 우선 1단계 완성 → 2~4단계 → 5단계 최종보스 → 1~5단계 검증 후 6~10단계 → 마수 구간 검증 후 인간 세력

20단계를 한 번에 만들지 않는다. 먼저 1단계의 전체 흐름을 완성한 뒤 데이터를 교체하는 방식으로 늘린다.

## 19. 개발 완료 기준

- 엘리트가 정확히 1분 40초와 3분 40초에 등장
- 엘리트가 총 2마리를 초과하지 않음
- 엘리트 처치 보상이 한 번만 지급
- 살아 있는 엘리트가 보스 등장 시 제거되고 강화로 변환
- 보스가 5분 50초에 등장
- 보스 등장 후 일반 자연 생성 중단
- 보스 페이즈 전환이 체력 기준으로 한 번만 발생
- 보스 처치 즉시 적 공격과 피해 판정 중단
- 남은 경험치 자동 회수
- 클리어 후 다음 단계 해금
- 8분까지 보스가 생존하면 실패
- 재도전 시 모든 스테이지 상태가 정상 초기화
- 같은 난수 시드로 적 생성과 엘리트 순서를 재현 가능

## 20. MVP 권장 범위

- 1단계 잿빛 숲
- 일반 마수 2종
- 엘리트 2종
- 일반 보스 1종
- 엘리트 흡수 강화
- 클리어와 실패
- 레드 드래곤만 사용

1단계가 완성되면 2~4단계는 적 조합과 환경 패턴을 추가한다. 5단계에서 첫 다중 페이즈 최종보스를 구현한다. 뽑기, 다른 드래곤, 장비, 도감은 이번 개발 단계에 포함하지 않는다.
