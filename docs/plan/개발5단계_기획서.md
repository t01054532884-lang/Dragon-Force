## v1.0 — 개발 적용 권장안

### 1. 핵심 기획 결정
| 결정 항목 | 최종 권장안 |
|---|---|
| 시스템 이름 | 드래곤 성장 연구소 |
| 성장 방식 | 모든 드래곤에 공통 적용되는 계정 영구 강화 |
| 강화 항목 | 공격력, 최대 HP, 이동속도, 경험치 획득 반경 |
| 최대 레벨 | 20 / 20 / 10 / 10 |
| 비용 | 초기 50G, 레벨에 따라 1.20배 증가 |
| 골드 획득 | 클리어, 실패, 보스 처치 보상 |
| 연구소 위치 | 메인 로비 + 결과 화면 바로가기 |
| 저장 | 브라우저 로컬 저장소, 저장 버전 관리 |
| 초기 성장 재화 | 0G |
| 초기 드래곤 | 레드 드래곤 |
| 필수 개발 범위 | 강화·구매·골드 정산·저장·UI·테스트 |

설계 원칙
1. 기본 공격 Lv.1~7과 영구 성장 레벨은 별개. 판 안의 강화는 끝나면 초기화, 연구소 강화는 유지.
2. 기본 공격과 액티브 스킬 모두 영구 공격력 보너스 적용. 향후 드래곤 10종도 같은 혜택.
3. 영구 강화는 골드를 지불하고 명시적으로 구매. 자동 강화 없음.

### 2. 영구 성장 항목 4종
- 공격력 Lv.0~20: 레벨당 모든 공격 피해 +2% (최대 +40%)
- 생명력 Lv.0~20: 레벨당 최대 HP +3% (최대 +60%). 전투 중 회복량 자체는 바꾸지 않음
- 비행속도 Lv.0~10: 레벨당 이동속도 +1% (최대 +10%). 적·투사체 속도에는 영향 없음
- 경험치 흡수 Lv.0~10: 레벨당 보석 획득 반경 +5% (최대 +50%). 획득량이 아니라 반경

계산: 연구소 보정치 = 1 + 강화 레벨 × 증가율. 기본 능력치는 기존 코드 값을 그대로 쓴다.
패시브와 겹치면 기본 능력치에 영구 강화와 패시브 보정을 **더해서** 적용(영구 +20%, 패시브 +40% → 1.60배. 1.20 × 1.40 = 1.68배로 중첩하지 않음).
영구 강화 Lv.0은 4단계 전투와 완전히 같아야 한다.

### 3. 강화 비용
C(n) = ceil(50 × 1.20^(n−1)), n = 구매 후 도달 레벨. 항목별 독립, 기본 비용 동일, 최대 레벨이면 구매 불가.
Lv.1 50G · Lv.2 60G · Lv.3 72G · Lv.5 104G · Lv.10 258G · Lv.15 642G · Lv.20 1,598G.
누적: 0→10 1,301G, 0→20 9,342G, 4종 만렙 21,286G(60회 구매). 비용 배율은 상수로 분리.
(이전 AI 제안 50 × 1.25^레벨은 레벨 0부터 계산하면 Lv.1 50G, Lv.10 약 373G, Lv.20 약 3,470G — 레벨 표시가 한 칸 어긋나 있었다.)

### 4. 골드 보상
최종 골드 = 기본 보상 + 생존 보상 + 처치 보상 + 엘리트 보상 + 보스 보상 + 클리어 보너스
| 보상 | 계산 |
|---|---|
| 기본 보상 | 30G |
| 생존 보상 | 생존 30초마다 +10G |
| 일반 적 처치 | 20마리마다 +5G (최대 80G) |
| 엘리트 처치 | 1마리당 +20G |
| 보스 처치 | +50G |
| 스테이지 클리어 | +100G |
8분 생존·보스 처치·클리어 시 340~460G.
예외: 30초 이내 중도 포기 0G / 30초 이후 사망은 실적만큼 / 보스는 잡았지만 클리어 조건 미충족이면 보스 보상까지 / 같은 엘리트·보스는 한 번만 / 클리어 보너스는 스테이지 완료 이벤트에서만 / 재시작·결과 화면 재진입 시 중복 정산 금지. 골드가 유일한 재화.

### 5. 화면 흐름
메인 로비(드래곤 선택 · 스테이지 선택 · 성장 연구소) → 전투 → 결과 화면(골드 정산 · 클리어/실패 · 재도전 · 연구소 · 로비). 전투 중에는 연구소 접근 불가.

### 6. 연구소 UI 요구사항
현재 레벨·다음 효과·필요 골드 표시 / 구매 후 즉시 갱신 / 골드 부족 시 비활성화와 안내 / 최대 레벨 MAX / 구매 이펙트·효과음 / 모바일 세로 화면에서 4종이 스크롤 없이 / 다시 열어도 유지.

### 7. 데이터 구조
`UpgradeType = attack | hp | speed | pickup`, `PermanentUpgrades`, `PlayerProgress { saveVersion, gold, upgrades, unlockedStages, selectedDragonId, rewardedRunIds }`, `PERMANENT_UPGRADES { maxLevel, bonusPerLevel }`, `getUpgradeCost(currentLevel) = ceil(50 × 1.2^currentLevel)`.
구매 순서: 버튼 → 현재 레벨 → 최대 확인 → 골드 비교 → 차감 → 레벨 +1 → 한 번에 새 상태 → 저장 → UI → 이펙트. 연속 클릭에도 중복 차감·음수 금지.
적용 시점: 전투 시작 때 기본 능력치 → 영구 강화 적용 → 고정. 피해 계산에서 영구 배율은 한 번만.

### 8. 저장
localStorage(같은 브라우저·사이트만). 첫 실행 0G·Lv.0 / 구매 즉시 저장 / 전투 종료 시 골드·진행도 저장 / 새로고침·재접속 복구 / 손상 데이터는 기본값으로 복구하고 가능하면 백업 / 이전 버전은 마이그레이션 / 4단계 해금·시드 재현을 덮어쓰지 않음 / 개발용 초기화는 확인 절차.

### 9. 밸런스 검증 구간
연구소 Lv.0(기존 유지) / 초반(공 +10%, HP +15%) / 중반(+20%, +30%) / 최대(+40%, +60%). 엘리트 1 18~22초, 엘리트 2 22~28초, 보스 55~75초 목표는 Lv.0 기준.

### 10. 꼭 확인할 테스트
49G로 50G 구매 실패 / 50G로 구매 → 0G·Lv.1 / 공격력 Lv.20 +40% MAX / HP Lv.20 +60% MAX / 비행속도 Lv.10 +10% MAX / 흡수 Lv.10 +50% MAX / 결과 화면 여러 번 → 중복 없음 / 연구소 새로고침 → 유지 / 음수 골드 → 보정 / 이전 버전 → 해금 유지 / Lv.0 → 기존 DPS / 연속 클릭 → 중복 차감·음수 없음.

### 11. 작업 순서
5-1 데이터·비용 / 5-2 골드 정산·중복 방지 / 5-3 구매·능력치 적용 / 5-4 저장·호환 / 5-5 연구소 UI / 5-6 결과 화면 연결 (이상 필수) / 5-7 로비(중요) / 5-8 테스트·GitHub Pages 배포(필수) / 5-9 이펙트·사운드(추후).

## v1.1 — 골드 및 HP 시스템 수정 요청
(AI 검토 질문 4개에 대한 답. 11/17 확정 골드 규칙을 유지하면서 반영)
1. **생존 보상**: 클리어 시 보스 처치 시각과 관계없이 8분 전체 160G. 실패 시 실제 생존시간 30초마다 10G.
2. **골드 정산**: 클리어 100%, 사망 50%. 보물 더미(+20G)는 총 획득 골드에 포함하고 실패하면 50%. 보물 더미 골드는 전투 중 임시 기록 후 종료 시 정산. 전투별 정산은 한 번만. 클리어 보너스는 클리어 때만.
3. **HP 피해 상한**: 35% 제한 유지. 기준은 연구소 강화 전 해당 드래곤의 기본 최대 HP로 고정. 영구 HP 강화로 상한이 늘지 않게. 기존 제한이 적용되던 공격에만.
4. **단계별 골드**: 1단계 1.0배, 2단계 1.2배, 3단계 1.4배, 4단계 1.6배, 5단계 1.8배. 원금 × 스테이지 배율 × 결과 배율 후 최종 금액만 버림. 보물 더미도 배율 대상.
5. **사망·포기**: 30초 미만 사망은 기본 골드부터 계산해 50%. 30초 미만 자발적 포기 0G. 30초 이상 포기는 총 획득 골드의 50%. 일시정지 화면에 계속하기·포기하기, 포기 시 확인 팝업, 확정 후 정산하고 결과 화면/로비로.
6. **테스트**: 클리어 시각이 달라도 생존 보상 동일 / 실패 시 보물 더미까지 50% / 영구 HP 강화 시 상한 불변 / 30초 이내 사망과 포기 보상이 다름 / 포기·사망·클리어 중복 정산 없음 / 기존 저장 데이터와 1~4단계 전투 정상.
