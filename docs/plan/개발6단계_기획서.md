## HTML 편집본에서 덧붙인 개발 주의사항
- 초기 재화는 소환권 하나로 운영해 연구소 골드와 소환 비용이 충돌하지 않게 한다. 보장 규칙은 원문의 초기 제안 기준이며 경제 밸런스 시뮬레이션이 필요하다. 확률 확인 화면을 제공하고 유료 재화 도입 시 원문에 명시된 플랫폼·출시 지역 검토를 진행한다.
- 10회 보장이 연속 미획득형인지 고정 10회 구간형인지, 일반 소환에서 희귀 이상 획득 시 카운터를 초기화하는지, 두 보장의 동시 발동 우선순위와 보장 등급 내 추첨 분포는 원문에 명시되지 않았다. 구현 전 결정한다.
- 최대 5성까지만 개발한다. 전설 승급 난도를 고려해 이벤트·범용 조각 경로를 검토하되 구체 수급량은 미정이다. 레드는 소환 제외이므로 별도 조각 수급 경로가 필요하다.
- 기준점: 연구소 Lv.0 · 드래곤 영구 Lv.1 · 1성에서 기존 레드 DPS를 보존한다. 따라서 레벨 증가율은 Lv.1 기준 초과 레벨에 적용하는 해석이 자연스럽다. 이 해석의 Lv.30은 공격력 +29%, HP +43.5%이며 최종 공식 승인 전에는 확정 수치로 취급하지 않는다.
- 개발 명세 표: 정의/소유 분리 · 공통 기본 공격 엔진(레드 코드를 10개 복사하지 않음) · 상태이상 공통 모듈(미정 확률·기간은 명시적 구성값) · 소환 원자성(재화 차감→추첨→신규/조각→천장→저장) · 전투 도중 드래곤 변경 금지 · 저장 마이그레이션 · 결제 연결 시 서버 검증

# Dragon Force 개발 6단계 — 드래곤 캐릭터·소환·육성 시스템 기획서 v1.0
(기획 초안 · 개발팀 검토용)
이번 6단계에서는 지금까지 만든 **레드 드래곤 중심의 전투 시스템을 총 10종의 드래곤으로 확장**하는 것이 목표야.
위에 만든 이미지는 드래곤 캐릭터, 소환, 육성, 선택 화면이 어떻게 구성될지 보여주는 콘셉트 시안이야. 아직 게임에 구현된 화면은 아니고, 아래 기획에서 제시하는 수치 역시 밸런스 테스트 전의 제안값이야.
## 1. 6단계의 핵심 목표
1. 드래곤 10종을 구현하고, 각 드래곤에 고유 속성과 외형을 부여한다.
2. 기존 레드 드래곤의 기본 공격 Lv.1~7 구조를 모든 드래곤에 확장한다.
3. 드래곤별 고유 특성을 적용해 같은 스킬을 선택해도 다른 전투 경험을 제공한다.
4. 드래곤 소환(뽑기), 이벤트 획득, 중복 획득 보상을 구현한다.
5. 드래곤 레벨과 승급을 통한 영구 육성을 추가한다.
6. 캐릭터 선택, 상세정보, 소환, 도감 화면을 구현한다.
**5단계와의 연결:** 5단계 연구소 강화는 모든 드래곤이 공유하고, 6단계의 드래곤별 레벨·승급은 해당 드래곤에게만 적용하자. 이 두 시스템은 서로 독립적이어야 해.

## 3. 기본 공격 Lv.1~7 성장 규칙
6단계에서 가장 중요한 부분이야.
기존 레드 드래곤의 기본 공격 Lv.1~7을 다른 드래곤에도 동일한 프레임워크로 적용하되, **성장할 때 강화되는 요소는 드래곤마다 다르게** 하자.
### 레드 드래곤 성장 예시
| Lv.1 | 화염탄 1발, 피해 계수 100% |
|--------|--------|
| Lv.2 | 화염탄 2발, 각 100% |
| Lv.3 | 화염탄 2발, 피해 +20% |
| Lv.4 | 화염탄 3발, 각 100% |
| Lv.5 | 화염탄 범위 +15% |
| Lv.6 | 화염탄에 화상 효과 추가 |
| Lv.7 | 화염탄 적중 시 소형 폭발, 폭발 피해 +30% |
Lv.3의 +20%는 Lv.4 이후에도 유지한다는 기준이야. 기존 구현과 다른 부분이 있다면 개발 시 기존 수치를 보존하고 별도 밸런스 변경으로 처리해야 해.
기본 공격은 **별도 전용 슬롯**을 사용하고, 기존 액티브 6개 + 패시브 4개 슬롯을 차지하지 않게 하자.
또한 기본 공격은 전투 중 레벨업 카드와 스킬 강화 상자에서 강화할 수 있지만, **전투가 종료되면 다시 Lv.1로 초기화**돼. 영구 육성으로 기본 공격의 세부 효과를 더 강하게 만드는 것은 가능하지만 처음부터 Lv.7로 시작하는 구조는 피하는 게 좋아.

## 5. 드래곤 획득 시스템 — 소환과 이벤트
드래곤은 기본 지급 1종과 획득형 9종으로 나누자.
**레드 드래곤은 모든 플레이어가 처음부터 보유**하며, 중복 소환 대상에서는 제외하는 방향을 추천해. 대신 나머지 9종은 소환·이벤트·미션으로 획득할 수 있어.

| 영웅 | 윈드, 워터 | 7% |
| 전설 | 아케인 | 1% |
| **합계** | **9종** | **100%** |
동일 등급 안에서는 기본적으로 균등 확률을 적용하자. 예를 들어 일반 등급의 드래곤 3종은 각각 약 23.33%야.
다만 실제 출시할 때는 해당 확률을 이용자가 명확히 확인할 수 있도록 고지하고, 유료 재화로 소환할 계획이라면 플랫폼의 확률형 아이템 정책과 해당 지역 법규도 별도로 검토해야 해.
### 소환 비용 제안
처음에는 복잡한 유료 재화 대신 **소환권** 하나만 운영하는 걸 추천해.
- 1회 소환: 소환권 1장
- 10회 소환: 소환권 10장
- 소환권 획득: 최초 클리어, 이벤트, 업적 보상
- 최초 소환 체험: 튜토리얼 보상으로 소환권 1장 지급
이렇게 하면 5단계 연구소 골드와 드래곤 소환 재화가 충돌하지 않아.
### 천장 시스템
드래곤 소환에서 지나치게 운이 나쁜 이용자를 위한 보장 규칙도 필요해.
- 10회 소환마다 희귀 이상 1회 보장
- 90회 이내 전설 1회 보장
- 전설을 획득하면 전설 보장 카운터 초기화
- 희귀 이상 보장과 전설 보장은 별도로 관리
이는 **제안 규칙**이고 아직 뽑기 경제 밸런스를 검증하지 않았으므로 최종 확정 전에 시뮬레이션이 필요해.

## 6. 중복 획득과 드래곤 육성
드래곤이 이미 있는데 또 같은 드래곤을 소환했다면, 중복 캐릭터를 없애는 대신 **승급 재료인 드래곤 조각**으로 변환하자.
### 드래곤 레벨
드래곤마다 개별 영구 레벨을 갖도록 설계하자.
| 시스템 | 규칙 |
|--------|--------|
| 드래곤 레벨 | Lv.1~30 |
| 강화 재화 | 골드 + 드래곤 성장 재료 |
| 공격력 증가 | 레벨당 +1% |
| HP 증가 | 레벨당 +1.5% |
| 레벨 초기화 | 전투 종료 시 유지 |
| 적용 대상 | 해당 드래곤에만 적용 |
여기서 중요한 점은 **드래곤 영구 레벨과 전투 중 기본 공격 레벨은 완전히 다르다**는 거야.
예를 들어 레드 드래곤의 영구 레벨이 15라도, 전투 시작 시 화염탄의 기본 공격 레벨은 Lv.1로 시작하는 거지.
### 드래곤 승급
## 드래곤 별 등급 성장
승급 별 등급에 따른 추가 능력치 보너스 예시
| 승급 | 필요한 조각 | 보상 예시 |
|--------|--------|--------|
| 1성 → 2성 | 20개 | 공격력 +5% |
| 2성 → 3성 | 40개 | HP +5% |
| 3성 → 4성 | 80개 | 고유 특성 강화 |
| 4성 → 5성 | 160개 | 공격력 +10%, 고유 특성 추가 강화 |
조각 지급은 일반 중복 +10개, 희귀 +20개, 영웅 +40개, 전설 +80개를 초기값으로 잡을 수 있어.
다만 이 구조를 그대로 적용하면 전설 드래곤의 승급 난도가 매우 높을 수 있으므로, 이벤트 보상이나 범용 조각 등 대체 획득 경로도 함께 고려해야 해.
**승급은 최대 5성으로 제한**하고, 처음부터 6성 이상을 개발하지 않는 게 좋아.

## 7. 캐릭터 선택 및 상세 화면
6단계에서 꼭 필요한 UI는 크게 세 가지야.
image_group{"query":["fantasy mobile RPG dragon character selection screen portrait UI dragon collection cards game interface"],"aspect_ratio":"3:4","layout":"carousel","num_per_query":1}
**드래곤 선택 화면**
보유한 드래곤 목록, 잠금 상태, 현재 선택한 드래곤, 속성 등을 표시.
image_group{"query":["fantasy mobile dragon RPG character details upgrade screen stats skill icons colorful game interface"],"aspect_ratio":"3:4","layout":"carousel","num_per_query":1}
**드래곤 상세 화면**
능력치, 기본 공격 Lv.1~7 미리보기, 고유 특성, 육성 레벨, 승급 정보 표시.
추가로 소환 화면에는 소환권 수량, 소환 확률, 획득 결과, 중복 조각 전환, 천장 진행도 등을 보여주면 돼.
캐릭터를 선택하고 전투 시작을 누르면 해당 드래곤의 모델, 기본 공격, 효과음, 속성이 불러와지는 구조야.
### 개발 시 능력치 적용 규칙
5단계 연구소와 6단계의 육성이 함께 적용되므로 계산 기준을 명확히 해야 해.
초기에는 같은 능력치에 대한 영구 보너스를 합산하는 방식이 좋아.
예를 들어:
- 드래곤 기본 공격력: 100
- 연구소 공격력: +20%
- 드래곤 레벨: +10%
- 승급 효과: +5%
최종 영구 공격력은 `100 × (1 + 0.20 + 0.10 + 0.05) = 135`가 되는 거야.
전투 중 패시브까지 더해지는 방식도 기존 5단계에서 확정한 합산 원칙을 유지하자.
다만 **연구소 Lv.0, 드래곤 영구 레벨 Lv.1, 승급 1성 상태에서는 기존 레드 드래곤의 DPS가 변경되면 안 돼.**

## 8. 개발 구현 구조
현재 웹 기반 게임이고 타입 검사를 통과한 상태라는 점을 고려해 TypeScript 형태의 예시를 제시할게. 실제 저장소를 직접 확인한 것은 아니므로 기존 클래스와 파일 이름은 개발자가 맞춰야 해.
```ts
type DragonRarity =
  | "starter"
  | "common"
  | "rare"
  | "epic"
  | "legendary";
type DragonElement =
  | "fire"
  | "ice"
  | "lightning"
  | "poison"
  | "light"
  | "dark"
  | "earth"
  | "wind"
  | "water"
  | "arcane";
interface DragonDefinition {
  id: string;
  name: string;
  element: DragonElement;
  rarity: DragonRarity;
  baseAttack: number;
  baseHp: number;
  baseMoveSpeed: number;
  basicAttackId: string;
  passiveTraitId: string;
}
interface OwnedDragon {
  dragonId: string;
  level: number;
  stars: number;
  shards: number;
}
interface DragonCollection {
  selectedDragonId: string;
  ownedDragons: Record<string, OwnedDragon>;
  summonTickets: number;
  pullsSinceLegendary: number;
  pullsSinceRareOrHigher: number;
}
```
### 중요한 구현 원칙
- 드래곤의 캐릭터 정의와 플레이어의 소유·육성 데이터를 분리한다.
- 기본 공격은 공통 공격 엔진에서 실행하고, 드래곤별 공격 패턴·투사체·상태이상만 데이터로 구분한다.
- 소환 결과는 서버가 없는 현재 데모 환경에서는 로컬 저장이 가능하지만, 실제 결제와 연결하는 순간 서버 검증이 필요하다.
- 소환 재화 차감·드래곤 지급·중복 조각 전환·천장 갱신은 하나의 트랜잭션처럼 처리한다.
- 드래곤 선택 후 전투 시작 시 능력치를 계산하고, 전투 도중에는 다른 드래곤으로 변경하지 않는다.
- 기존 레드 드래곤 데이터와 저장 기록이 손실되지 않도록 세이브 마이그레이션을 추가한다.

| 6-4 | 고유 특성·Lv.1~7 | 모든 드래곤 성장 적용 |
| 6-5 | 캐릭터 선택 UI | 선택한 드래곤으로 전투 시작 |

특히 6-1과 6-2를 먼저 완성한 뒤, 동일한 구조로 나머지 드래곤을 추가해야 해. 레드 드래곤에 맞춰 작성한 코드를 10개 복사하는 방식은 피하자.
