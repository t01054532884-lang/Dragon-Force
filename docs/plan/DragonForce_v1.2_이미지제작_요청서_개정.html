2. 공통 규격

  • 1024×1024 PNG, 투명 배경(투명이 안 되면 순수 초록 #00FF00 배경). 그림은 캔버스 가운데, 여백은 사방 약 8% 고르게.
  • 글자·숫자·워터마크 없음. 파일 이름은 표의 이름 그대로(영문 소문자·하이픈).
  • 화풍 맞추기 첨부(매번 같이): portrait-red.webp(레드 드래곤 초상), skill-meteor.webp(이미 받은 스킬 아이콘). 상자는 chest-equipment.webp도 같이.
  • 화풍: 귀여운 SD 판타지, 부드러운 3D 채색, 은은한 광택, 선명한 색, 위쪽 왼쪽 광원.
  • 80px로 줄였을 때도 형태가 보여야 함 — 상징 하나를 크게, 잔무늬 최소.
  • 폴더: ACTIVE_ICONS · RUNES · SHOP · SIGILS · REWARD_FRAMES · HARD_MODE_UI. 검수 시트(전체 모음)는 따로 1장 더 — 시트만 주면 안 됩니다.

4. 룬 아이콘 15장 rune-<id>.png + 룬 조각 1장 변경

룬은 연구소 “룬” 탭에서 키우는 능력치 성장 아이템입니다(이전 “특수 스킬”을 바꾼 것, 이름은 그대로). 해금한 룬은 장착 없이 전부 항상 적용됩니다.

화면위치크기
연구소 → “룬” 탭5칸 × 3줄 육각형 칸 안(칸은 게임이 그림: 남색 육각 + 룬 색 빛). 잠긴 룬은 어둡게약 80px
같은 탭 아래 상세 판고른 룬 큰 그림 + “공격력 +6%” 같은 효과 + 강화 버튼약 120px
상점 → 룬 상자 결과“용의 분노 룬 · 룬 조각 +10” 카드약 96px

그림 방향: 배지·사각 틀 없음. 작은 육각형 룬석(돌 판) 위에 빛나는 문양 하나가 새겨진 모양, 육각형 안에 쏙 들어가게(꼭짓점이 위·아래). 룬석은 15장 모두 같은 짙은 남색 돌 + 은은한 금 테로 통일하고, 문양 모양과 빛 색만 룬마다 다르게(아래 색 지정). 비슷한 효과는 모양으로 구별.

10. 납품과 회신

  • 1차: 전용 액티브 아이콘 10장 낱개 PNG + 검수 시트 + “파일 이름 → 드래곤·스킬 이름” 목록.
  • 검은 배경·흰 배경 둘 다에서 가장자리 번짐·사각 배경이 없는지, 80px 축소본에서 형태가 보이는지 확인해 표시해 주세요.
  • 표에 없는 내용은 새로 만들지 말고 질문으로 묶어 주세요. 참고 시안(REFERENCE_ONLY)은 분위기 참고만, 그림·이름을 가져오지 않습니다.
  • 받으면 개발 쪽에서 투명 여백 정리 → 256/512 WebP 변환 → 게임 연결 → 화면 확인까지 합니다.
