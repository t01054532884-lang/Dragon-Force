# 스킨 · 스킨 룰렛 · 장비 착용 모습 · 단계 상자 25/50/100% (2026-11-23 밤)

제작자 요청(같은 날 밤): 남은 드래곤 4종 출시, 단계 상자를 참고 화면처럼, 장비를 끼면 드래곤에 보이게, 장비 메뉴에 스킨(망토·발자국), 겨울 축제 아래 스킨 룰렛(열쇠 4,900원, 뽑힌 칸 제외), 힉스필드로 고퀄리티 UI·스킬·홍보 영상.

## 1. 확정(제작자 답변 2026-11-23 밤)
| 항목 | 결정 |
|---|---|
| 단계 상자 | **고른 단계마다 3개(25·50·100%)**. 25% = 그 단계에서 첫 엘리트 처치, 50% = 두 번째 엘리트 처치, 100% = 클리어. 닫힘 → 도달하면 반짝임 → 받으면 열린 상자. 최초 보상이라 다른 단계에 갔다 와도 열린 채 |
| 열쇠 | **현금 결제만**(App Store 소모성 상품 `skin_key_1`, 4,900원, 1개). 웹·토스는 결제가 없어 룰렛 버튼이 안 보임 |
| 장비 착용 모습 | **레드 먼저, 4부위 겹치기**. 맞으면 다른 드래곤으로 확대 |

## 2. 단계 상자(`src/systems/Progress.ts` 단계 상자 구역, `src/scenes/LobbyScene.ts` `progressChests`)
- 저장: 난이도마다 `chests`(받은 상자 = 단계×10 + 칸) · `reach`(단계별 가장 멀리 간 칸 0~3). 클리어한 단계는 저장 없이 3.
- 정산: 판이 끝나면 클리어 3, 아니면 그 판 엘리트 처치 수(최대 2)로 `reach`를 올림(내려가지 않음).
- 보상: 예전 "단계 상자 1개" 몫을 세 칸으로 나눔 — 골드 30/30/40%, 루비 ⅓씩, 5단계마다 레드 조각은 100% 칸. 쉬움 1칸 = 골드 15·루비 5 / 15·5 / 20·5(+조각 5). **20단계 × 3칸 합계는 예전과 같음**(쉬움 골드 1,000·루비 300·조각 20, 어려움 2배).
- 이어받기: 예전에 단계 상자 1개를 받은 단계는 세 칸 모두 받은 것으로 옮김(이중 지급 없음).
- 로비: 판 위 제목 "쉬움 N단계 상자", 오른쪽에 다른 단계에 받을 상자 수, 막대가 0→25→50→100%로 참. 열린 상자는 상자 본체 뒤로 뚜껑을 젖힌 모양 + 안쪽 금빛(기존 상자 본체·뚜껑 그림 재사용, 새 그림 없이). 5단계마다 100% 칸은 드래곤 상자 그림.
- **확인할 점**: 1단계 봇 측정에서 두 번째 엘리트는 처치 전에 보스에게 흡수되는 판이 많았다(19종 중 다수 `null`). 그런 판은 50% 상자가 클리어 때 함께 열린다. 엘리트 처치가 아니라 "그 시점까지 생존"으로 바꿀지 → 제작자 판단(지금은 처치 기준).

## 3. 스킨(`src/data/skins.ts`, `src/systems/Skins.ts`, `src/ui/skinArt.ts`)
- 망토 3종(불꽃왕·서리 왕관·별빛), 발자국 6종(불꽃·서리·별가루·꽃잎·번개·그림자). **꾸미기 전용 — 능력치·전투력 없음.** 계정 공통(어느 드래곤으로 출격해도 같은 스킨).
- 장비 화면 위 탭 **장비 | 스킨 N**: 스킨 탭 = 전투 모습 미리보기(위에서 본 드래곤이 원을 돌며 망토·발자국) + 망토 줄 + 발자국 줄(없음/가진 것, 누르면 장착) + "스킨 룰렛 가기".
- 전투: 망토는 드래곤 아래층에 붙어 함께 회전·펄럭임, 발자국은 26px 움직일 때마다 하나 남고 0.7초에 사라짐. 판정·적 공격 예고를 가리지 않게 바닥 바로 위 층(깊이 2).
- 그림이 오기 전에는 색 값으로 그린 **도형 임시 그림**. 그림이 오면 같은 키로 연결(아래 6절).

## 4. 스킨 룰렛(`src/scenes/SkinScene.ts`, 키 `skins`)
- 입구: 로비 왼쪽 겨울 축제(이벤트) 바로 아래 "스킨 룰렛". 왼쪽은 4칸까지라 넘치는 출석은 오른쪽 패스 아래로. 열쇠가 있고 남은 칸이 있으면 "!".
- 판 9칸(3×3, 가운데 큰 칸 = 그 주의 대표 망토). 열쇠 1개로 1회, 빛이 남은 칸을 돌다 멈춤 → 보상 창. 뽑힌 칸은 "획득"으로 어둡게, 다시 안 나옴.
- 매주 월요일 0시(KST) 새 판(묶음 3개가 차례로: 불꽃왕+불꽃·별가루 → 서리 왕관+서리·번개 → 별빛+꽃잎·그림자). 남은 시간 표시. 열쇠는 남고 받지 못한 칸은 사라짐.
- 이미 가진 스킨이 다시 판에 오면 그 칸은 **루비 500**(11/24 제작자: 1,500은 과함 → 열쇠 1개 값어치).
- **추첨은 서버**(11/24): `functions/` `skinState`·`skinSpin`·`skinAck`, 공용 규칙 `src/data/skinRoulette.ts`. 남은 열쇠 = 장부의 열쇠 구매(환불 제외) − 서버 사용 수. 앱 저장을 되돌려 다시 뽑기·열쇠 조작을 막음. 개발 모드(서버 없음)만 기기 추첨.
- 처음 가중치(AI 1차안, 임시) — 합 100이라 첫 1회 확률 = 숫자 %:

| 칸 | 가중치 |
|---|---|
| 루비 300 | 20 |
| 골드 30,000 | 18 |
| 드래곤 상자 개봉권 3장 | 14 |
| 장비 상자 개봉권 5장 | 14 |
| 루비 1,000 | 8 |
| 영웅 드래곤 정수(영웅 중 하나) | 6 |
| 발자국 A · B | 8 · 8 |
| **가운데 망토** | **4** |

- 확률 창: 지금 판 기준 다음 1회 확률(남은 칸 가중치로 다시 나눈 값)과 규칙을 그대로 보여 줌(확률형 아이템 표시 — 단계마다 확률이 바뀌는 방식이라 "지금 판 기준"으로 표시).
- **가운데 망토까지 필요한 열쇠(100만 번 모의, `node`로 계산)**: 평균 **6.8개(약 33,400원)**, 누적 확률 4개 19.5% · 6개 35.5% · 8개 64.5% · 9개 100%(44,100원). 망토 가중치 4는 "가장 마지막 쪽에 나오는 대표 상품" 의도. 더 일찍 나오게 하려면 `SKIN_ROULETTE.capeWeight`만 바꾸면 됨.
- 결제: `src/data/iap.ts`에 17번째 상품(`skinkey`). 서버 장부·지급·ack 경로는 기존과 같고, 앱은 `grantVerifiedSkinKeys`(같은 거래 1번)로 열쇠를 더함. 개발 모드 웹(`?dev=1`)은 "열쇠 구매"가 결제 없이 +1(시험용).

### 제작자 확인이 필요한 것
1. **주간 초기화 때 진행이 사라짐**: 열쇠 5개(24,500원)를 쓰고 망토를 못 받은 채 월요일이 되면 판이 새로 바뀌어 그 진행이 사라진다. 결제 불만이 생기기 쉬운 부분이라 ① 지금처럼 초기화 + 남은 시간 크게 표시, ② 판을 다 받을 때까지 이전 판 유지, ③ 초기화 때 못 받은 망토 진행을 다음 판으로 이월 — 중 고르기(지금은 ①).
2. **App Store 가격 등급**: 4,900원이 원화 가격 등급에 없으면 가장 가까운 값으로 등록(App Store Connect에서 확인). 상품 ID `skin_key_1`은 등록 뒤 바꿀 수 없음.
3. **열쇠 묶음**: 1개만 팔지, 5개·9개 묶음(할인)도 둘지.
4. 재화 칸 구성·수량(루비 300/1,000, 골드 30,000, 개봉권 3/5장, 영웅 정수)은 AI 1차안. 루비 상품 기준 열쇠 1개(4,900원) ≈ 루비 410~670 가치.
5. 참고 화면(세 번째 사진)은 다른 게임 화면이라 **방식만 참고**하고 그림·배치는 우리 것으로 만든다.
