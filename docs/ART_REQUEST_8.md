# 그림 요청서 8 — 장비 오라 · 장비 궤도 받침 (2026-11-24)

**제작자 결정(11/24)**: 장비를 드래곤 몸에 그려 입히지 않는다(레드 목걸이 편집 시험: 230px에서 티가 안 나고, 19종 × 4부위 = 76장이 필요해 늘어남).
대신 장비 화면 제단에서 **① 4부위를 모두 낀 등급 오라(드래곤 뒤) ② 낀 장비 아이콘이 드래곤 둘레를 타원으로 돎** — 19종 모두 바로 적용, 초상을 바꿔도 다시 할 일 없음.
코드는 이미 들어가 있고(`src/scenes/EquipScene.ts` `drawAura`·`drawOrbit`, 규칙 `equipAuraRarity`), 지금은 빛줄기 그림을 등급 색으로 물들인 **임시 연출**. 아래 그림이 오면 같은 이름으로 바꿔 끼운다.

## 오라 규칙
- 4부위(발톱 장식·비늘 갑주·목걸이·반지)를 **모두 끼었을 때**, 그중 **가장 낮은 등급**이 오라 등급. 일반이 하나라도 있으면 오라 없음.
- 희귀 = 파랑 `#4FC3F7`, 영웅 = 보라 `#BA68C8`, 전설 = 금빛 `#FFB300`.

## 공통 규칙
- **1024×1024, 완전 투명 배경 PNG.** 글자·테두리·카드·배경판·바닥·드래곤 없음. 기존 Dragon Force 부드러운 3D 화풍.
- 새 ChatGPT 대화에서 **한 메시지에 한 장씩**(이전 그림 반복 방지). 공유 링크로 주면 AI가 가공·연결.
- 붙일 공통 문장:
  > 게임 UI 이펙트 스프라이트. 1024×1024 완전 투명 배경 PNG, 글자·테두리·배경판·바닥·캐릭터 없음. 기존 Dragon Force 부드러운 3D 화풍. 한 장만, 이전 대화의 이미지는 참고하지 말 것.

## ① 등급 오라 3장 `aura-equip-<등급>.png`
**게임에서**: 장비 화면 제단 위 드래곤 초상(230px) **뒤**에 360px로 깔리고, **24초에 한 바퀴 천천히 돌며** 밝기가 숨 쉬듯 변한다. → **돌려도 어색하지 않은 원형 대칭**이어야 하고, **가운데는 드래곤이 가리므로 부드럽게 비워** 둔다.
붙일 문장:
> 캐릭터 뒤에 까는 **원형 오라**. 가운데 지름 40%는 은은하고 비어 있게, 바깥으로 빛줄기가 방사형으로 뻗고, 작은 빛 입자가 둘레에 떠 있음. **원형 대칭**(회전해도 자연스럽게), 가장자리는 부드럽게 투명해짐. 바닥·땅·그림자 없음.

| `aura-equip-epic.png` | 영웅 | 보라(#BA68C8)와 분홍빛이 섞인 마력 오라, 빛줄기 더 많고, 별 모양 반짝임 |

## ② 장비 궤도 받침 4장 `equip-orb-<등급>.png`
**게임에서**: 낀 장비 아이콘(52px, 이미 있는 그림)이 드래곤 둘레를 도는데, 그 **아이콘 뒤에 74px 받침**으로 깔린다. 앞쪽으로 올 때 조금 커지고 뒤로 갈 때 작아진다.
→ **가운데는 아이콘이 올라가므로 반투명하게 비어 있는 둥근 메달/고리**.
붙일 문장:
> 작은 아이템 아이콘 뒤에 까는 **둥근 빛 받침(메달 고리)**. 가운데 지름 65%는 아주 옅은 반투명 빛만(아이콘이 올라감), 바깥은 얇은 금속 고리 + 부드러운 글로우. 위에서 정면으로 본 완전한 원, 좌우·상하 대칭. 작게(74px) 보여도 등급 색이 바로 구분되게.
