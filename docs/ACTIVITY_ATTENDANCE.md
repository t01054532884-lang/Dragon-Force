# 활동 점수 상자 · 상시 출석 보상표 (AI 1차안, 2026-11-21 — 제작자 판단 대기)

> 제작자 요청: "임의로 정해서 알려 주면 내가 판단할게". 목표는 예전에 잡은 **상시 루비 월 4,000~5,500**(꾸준히 매일 하는 사람 기준). 겨울 축제 출석(12월 한정)과는 별개로 **상시** 운영.

## 0. 지금 상시 루비 수급(참고)
- 월간 미션 "일일 미션 20일 완료" 300루비가 유일한 상시 루비. 나머지는 1회성(업적, 쉬움·어려움 최초 클리어 등, 어려움 최초 클리어 합계 2,300).
- 소환 가격: 드래곤 1회 250 · 10회 2,200 / 룬 상자 100 · 900.

## 3. 합계(매일 다 하는 사람, 한 달 ≈ 30일)
| 출처 | 루비 |

- 가볍게 하는 사람(출석만 + 일일 60점): 약 900 + 600 + 300 = **월 약 1,800**.

## 4. 화면(참고 UI 구성 반영)
- 보상 화면(미션) 탭: **정복 진행도 / 미션 / 업적** 앞에 **출석** 탭 추가, 미션 탭 위쪽에 **일일 활동 막대(20~100 상자 5개)** + 주간 막대.
- 상자 아이콘은 지금 있는 보상 그림(골드·루비·카드·조각)으로 먼저, 활동 상자 그림은 나중에 요청.

## 5. 결정 필요
1. 월 루비 총량(약 4,600) 괜찮은지 — 더 줄이려면 일일 100점 루비 50 → 30(월 −600).
2. 일일 미션 5개 구성(특히 "성장 1회" — 골드가 없으면 못 하는 날이 생김).
3. 출석 28일 반복 vs 달력(매월 1일 초기화).
4. 무료 개봉권 월 6장이 드래곤 수집 속도에 괜찮은지.
