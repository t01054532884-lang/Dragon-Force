# 재도전·행동력 점검 (2026-11-28, 제작자 제보)

**제보**: "바하무트를 쓰다가 포기 → 재도전을 눌렀더니 다른 드래곤이 나왔다. 재도전에 오류가 있는지, 행동력이 줄어드는지 전체 확인."

## 원인
- 재도전·"다음 단계"가 **단계·난이도만** 넘기고 드래곤은 넘기지 않았다 → 새 판이 **저장된 출격 드래곤**으로 시작.
  이번 판 드래곤이 출격 드래곤과 다르면(시험 탭에서 바하무트를 직접 띄운 경우 등) 재도전 때 출격 드래곤으로 바뀜.
- 결과 화면에서 재도전(또는 다음 단계)을 아주 빠르게 두 번 누르면 장면이 다시 시작되기 전에 입장이 두 번 처리돼 **행동력이 두 번 빠질 수 있는 틈**이 있었다.

## 고친 것
- `src/systems/battleEntry.ts`(새로, Phaser 없이 시험 가능): `retryData`·`nextStageData`가 **이번 판 드래곤·단계·난이도**(+ 무료 판·시험 출격 표시)를 그대로 넘김, `runEntry`(행동력 5 차감 → 부족하면 안내만), `createEntryGate`(결과 화면 하나에서 입장은 한 번만, 부족해 막혔으면 다시 누를 수 있음).
- `GameScene`: 재도전·다음 단계·R 키 모두 위를 씀. 무료 판(개발용 잠긴 난이도 시험)의 재도전도 무료로 이어짐.
- `ui/entry.ts`: `enterBattle`이 `runEntry`를 씀(규칙은 그대로: 입장·재도전·다음 단계 모두 5, 실패·포기 때 돌려주지 않음).

## 확인
- 테스트 7개 추가(`tests/retry.test.ts`): 24종 × 쉬움·어려움·매우 어려움 재도전·다음 단계 유지, 무료·시험 출격 유지, 5 한 번 차감, 부족하면 막힘·그대로, 두 번 눌러도 한 번만, 막힌 뒤 다시 누를 수 있음. 전체 313개.
- 브라우저 실제 흐름(타이틀 → 로비 → 전투 시작): 바하무트·어려움 20단계 입장 40→35 · 30초 전 포기 → 재도전 **두 번 클릭** 25→20 한 번, 같은 드래곤·단계·난이도 · 행동력 4에서 재도전 → 막힘 + "행동력이 부족해요" 안내, 그대로 4 · 출격 드래곤을 레드로 바꿔 둔 채 재도전 → 바하무트 그대로(원래 오류) · 시간 초과·쓰러짐(부활 이미 씀) 뒤 재도전 → 같은 판, 5 한 번, 부활 기록 초기화.
- 일시정지 메뉴에는 재도전이 없음(계속하기·포기하기만) — 포기 확정 → 결과 화면 → 재도전.
- 참고: 시험용으로 장면을 직접 띄우면 타이틀 장면이 뒤에 남아 전투가 로비 그림을 내릴 때 화면이 멈출 수 있음(개발 도구로만 생김, 실제 흐름에서는 타이틀이 꺼져 있음 — 확인함).
