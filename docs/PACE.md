# 전투 속도·성장 체감 개선 (2026-11-20)

제작자 추가 요청서 "전투 속도·성장 체감 개선" 1~7번 반영 기록. 방향은 제작자 확정, **수치는 자동 측정으로 정한 1차값**(사람 플레이·아이폰 검수 후 다시 조정).
우선순위: 전투 진행시간 → 몬스터·경험치·드롭 동시 조정 → 전용 스킬 → 조합 안내(요청서 순서 그대로).

## 2. 전용 스킬 10종 (괄호 = 이전)

공통: 광역 대상당 DPS × 4초(3초), 총합 상한 DPS × 24초(12초) → 적이 많아도 덜 약해짐. **보스는 한 번 사용에 최대 HP의 8%, 엘리트 25%까지만**(한 번에 사라지지 않게).

| 드래곤 | 종류 | 바뀐 것 |
|---|---|---|
| 레드 화염 폭풍 | 광역 | 반경 4 → 5m(+25%) |
| 블루 얼음 감옥 | 광역 | 4.5 → 5.6m, 빙결 2 → 2.5초, 둔화 3 → 4초 |
| 옐로 천둥 폭발 | 광역 | 5 → 6.2m, 감전 2 → 3초 |
| 그린 독의 영역 | 지속 | 3.5 → 4.4m, 총 DPS × 3 → 5초, **독구름이 드래곤을 따라다님**(맞히기 쉬움) |
| 화이트 신성한 가호 | 회복 | 회복 15 → 30%, + 4초 동안 받는 피해 −30%, + 주변 3m 밀쳐냄 |
| 블랙 암흑 폭발 | 전방 | 10m·폭 3m → 12m·폭 4.5m, **적이 가장 많은 방향으로 자동 조준**(엘리트·보스 가중) |
| 스톤 대지의 수호 | 방어 | −25%·4초 → −40%·6초, 밀쳐내기 3 → 4m + 적마다 DPS × 2초 피해 |
| 윈드 폭풍의 질주 | 이동 | +25%·5초 → +40%·6초, 회오리 2.5 → 3.2m, 총 DPS × 1 → 3초 |
| 워터 해일 | 전방 | 7m·폭 6m → 8.5m·폭 7.6m, 자동 조준, 둔화 2 → 3초 |
| 아케인 마력 폭주 | 단일 | 8발 → 10발, 합계 DPS × 4 → 9초, **보스 → 엘리트 → 가까운 적 순 조준**, 사거리 9 → 11m |

## 3. 자동 측정 (개발 전용 봇 `src/dev/bot.ts`, 콘솔 `await botRun({...})`)

봇은 단순 회피(원을 그리며 끌고 다님) + 보석 줍기 + 전용 스킬 자동 사용이라 **사람보다 피하지 못한다** — 같은 봇으로 기존 수치를 돌려도 1단계 44~88초에 쓰러졌다. 그래서 진행 시간은 체력 배율(hp ×4~40)을 준 봇으로 재고(피해를 거의 안 받는 숙련자 대용), 생존은 따로 본다. atk = 판 시작 공격력 배율(성장한 드래곤 흉내).

- 첫 성장: 1단계 레벨 2 도달 16~27초, 레벨 3 30~60초(첫 레벨 경험치 조정 뒤 시드 14: 21초·30초·44초). 봇이 보석을 늦게 줍는 판(63초)이 한 번 있었음.
- 아이템: 1단계 판마다 물약 1~6, 자석 1~4, 골드 7~19개(주운 골드 28~114G → 상한 80G). 같은 시드 20판 × 1,000마리 단위 테스트에서 물약·자석이 안 나온 판 0.
- 전용 스킬 10종(1단계, 같은 시드): 모두 발동·피해 확인. 전체 피해 중 비중 레드 4.3 · 블루 9.3 · 옐로 5.5 · 그린 5.0 · 화이트(회복형) · 블랙 7.3 · 스톤 5.8 · 윈드 8.8 · 워터 6.8 · 아케인 11.2%. 일반 적 체력 13~15라 광역 범위 안 일반 적은 한 번에 정리된다.

## 4. 최종 수치 재측정

최종 수치(가벼운 적 체력 상한 15, 첫 레벨 경험치 8·11·17, 골드 6G)로 1단계 레드, 시드 21~23, hp ×4:

## 5. 확인 요청·남은 일
1. **실제 아이폰 검수(요청서 7번 마지막)**: 적·경험치·효과가 겹칠 때 공격 예고가 보이는지. 이번에는 그리는 순서(보석·골드·아이템을 예고 아래로)만 바꿨고 기기 확인은 못 함.
2. 사람 플레이로 1단계 "약 5분" 체감 확인 → `pace()` 숫자만 바꾸면 됨.
3. 업적 "마수 누적 1,000/10,000마리"는 평생 목표라 그대로 둠(예전보다 2~3배 많은 판이 필요) — 낮출지 결정 필요.
4. 15단계 atk 2.6 보스전 258초는 긴 편(제한 10분 안). 후반 보스 체력 배율(×0.85)을 사람 측정 뒤 다시 볼 것.
