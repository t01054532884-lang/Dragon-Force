# 단계별로 배운 것

게임 개발을 처음 하면서 단계마다 새로 알게 된 개념을 짧게 적는다.

## 1단계 — 화면에 드래곤 띄우고 움직이기
- **게임 루프**: 게임은 1초에 약 60번 `update()`를 부른다. 매번 입력을 읽고 → 위치를 바꾸고 → 다시 그린다.
- **Scene(장면)**: Phaser에서 화면 하나 = Scene. `create()`는 처음 한 번(물체 만들기), `update()`는 매 프레임.
- **물리 몸체(body)**: `physics.add.image`로 만들면 속도(velocity)를 주는 것만으로 움직이고, 나중에 충돌 판정도 이걸로 한다.
- **월드와 카메라**: 맵(4000×4000)은 화면(720×1280)보다 크다. 카메라가 드래곤을 따라가고, UI는 `setScrollFactor(0)`으로 화면에 고정한다.
- **방향 벡터 정규화**: 오른쪽+위를 같이 누르면 (1, −1)이라 길이가 1.41 → 대각선이 더 빠르다. `normalize()`로 길이를 1로 맞춘다.
- **터치 조이스틱**: 누른 곳을 중심으로, 끌고 간 거리(최대 90px)를 0~1 세기로 바꿔 속도에 곱한다.
- **도형 텍스처**: `Graphics`로 원·삼각형을 그린 뒤 `generateTexture`로 그림처럼 쓴다. 그림 파일이 없어도 시작할 수 있다.
