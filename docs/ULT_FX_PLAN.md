# 필살기 전장 연출 개성화 기획 (2026-11-28, 제작자 지시 — 승인 뒤 구현)

## 규칙 (개발팀 고정 규칙)
- 드래곤 고유스킬(필살기)의 **인게임 전장 연출은 드래곤마다 "움직임의 형태"가 달라야 한다.**
- 색과 무기 모양만 바꾸고 같은 틀(예: 화면 위→아래로 쓸고 지나가는 띠)을 다시 쓰는 것은 안 된다.
- 기준: 신규 5종(전술 포대·세계수의 각성·대지 강타·수정의 폭발·용왕의 숨결)처럼 형태 자체가 다른 연출. 그 드래곤 속성이 바로 읽히게.
- 모두 화면 전체(광역)는 유지. 새 그림 생성 없이 **이미 있는 전장 효과 그림 + 코드 연출**로(크레딧 0).

## 새 연출 기획 14종 (서로 다른 축, 기존 10가지와도 안 겹치게)
| 드래곤 · 필살기 | 축 | 움직임 |
|---|---|---|
| 빙하 · 절대영도 | **가장자리 → 안쪽 결빙 + 깨짐** | 화면 네 가장자리에서 서리가 안쪽으로 번져 화면 전체가 얼음판이 됨 → 가운데부터 금이 가며 산산조각, 얼음 조각이 사방으로 |
| 옐로 · 천둥 그물 | **점 낙뢰 + 연결선** | 화면 곳곳 8~10곳에 번개가 차례로 내리꽂히고, 꽂힌 점끼리 번개 줄이 이어져 그물 → 그물 전체가 한 번에 번쩍 |
| 그린 · 독의 폭우 | **비 + 바닥 번짐** | 독비가 비스듬히 쏟아지고, 떨어진 자리마다 독 웅덩이가 부글부글 퍼졌다가 거품으로 터짐 |
| 화이트 · 성광의 기둥 | **십자 광선 회전** | 드래곤 자리에서 거대한 빛의 십자(세로·가로 빔)가 펼쳐지고, 빛살이 천천히 돌며 화면을 훑음 |
| 스톤 · 운석 낙하 | **대형 낙하 충돌(3발)** | 바닥에 그림자 원(예고) → 큰 운석 3개가 화면 밖에서 비스듬히 날아와 차례로 충돌, 크레이터·바위 파편·강한 흔들림 (기어스의 작은 포탄 여러 발과 달리 크고 느린 3발) |
| 윈드 · 대폭풍 | **이동하는 회오리** | 회오리 2개가 화면을 S자로 가로지르며 지나간 자리의 잎·먼지를 휘감아 올림 |
| 스틸 · 천 개의 검 | **격자 낙하·꽂힘 → 동시 폭발** | 검이 격자 모양으로 위에서 수직으로 차례차례 꽂히고(다다닥), 마지막에 모든 검이 한꺼번에 터지며 금속 파편 |
| 블룸 · 천화의 만개 | **나선 개화** | 드래곤 자리에서 나선을 그리며 꽃이 차례로 피어나 화면을 덮고, 꽃잎이 흩날림 |
| 하울 · 천지의 포효 | **박자 맞춘 음파 맥동** | 드래곤 자리에서 음파 고리가 "쿵·쿵·쿵" 3박자로 터지고, 박자마다 화면 전체가 확대·축소로 출렁임 |
| 크림슨 · 핏빛 초승달 | **X자 베기 + 화면 갈라짐** | 거대한 초승달 둘이 X자로 화면을 베고, 벤 선을 따라 화면이 잠깐 어긋났다 붙음 |
| 미러 · 거울 세계 | **화면 분할·반사** | 화면이 거울 조각 6~8장으로 갈라지고 빛줄기가 조각 사이를 튕겨 다니며 무지개로 반사 → 조각이 깨져 흩어짐 |
| 크로노 · 시간 정지 | **멈춤 → 되감기 → 시간차 다발 폭발** | 화면이 회색으로 멈추고(적 정지), 거대한 시계 바늘이 한 바퀴 돌며 색이 돌아오는 순간 멈춰 있던 적들 자리에서 차례로 폭발 |
| 보이드 · 사건의 지평선 | **흡입 → 붕괴 → 폭발** | 드래곤 앞 한 점으로 화면의 빛·파편이 빨려 들며 검은 구가 커졌다가 한 점으로 줄어드는 순간 바깥으로 대폭발 (워터는 도는 소용돌이, 보이드는 회전 없이 빨아들였다 터짐) |
| 오로라 · 극광의 심판 | **물결치는 커튼** | 극광 커튼 여러 겹이 화면 가로로 물결치며 색이 바뀌고, 커튼 끝에서 빛 방울이 떨어져 꽂힘 |

## 구현 방법(승인 뒤)
- 각 드래곤의 기존 전장 효과 그림(`ult-fx-<id>`)·전용 스킬 그림(`sigart-<id>`)을 잘라 쓰고 나머지는 도형·입자·카메라(흔들림·확대) 연출. 새 그림·영상 생성 없음.
- 한 연출 1~1.5초, 동시 물체 수 상한(렉 방지), 드래곤 화면 위치 기준(이미 넘김).
- 확인: 브라우저에서 14종 각각 한 프레임씩 녹화(60fps)해 서로 겹치지 않는지 모아 보기로 검수 → 제작자 확인.
