## v1.2 전투 아이템 드롭
| 아이템 | 효과 | 구현 |
|---|---|---|
| 스킬 강화 상자 | 보유 기본공격·액티브 중 최대 3개 → +1레벨 | 레벨업 카드와 같은 화면(금색 테두리, "Lv.2 → Lv.3"). 후보는 아이템 전용 난수로 섞음 |
| 회복 물약 | 실제 최대 HP 25% | 최대 HP 초과분은 버림 |
| 경험치 자석 | 맵 전체 보석을 끌어옴 | 보석에 표시만 붙여 빠르게(1400px/초) 날아오게 함. 경험치 값·레벨업 로직 그대로 |
| 용의 수호막 | 1회 피해 0, 60초 | 피해 계산 맨 앞에서 판정, 막고 0.5초 무적, 다시 얻으면 60초로 갱신. 드래곤 주위 푸른 원 + HUD 남은 초 |

- 일반 몬스터 드롭 0.10 / 0.18 / 0.12 / 0.10%(v1.3에서 상자 0.02%로), 처치마다 한 번(`src/data/items.ts`에 모음). 엘리트는 강화 상자 확정(사라지지 않음), 보스는 아이템 없음.
- 일반 드롭 30초 후 소멸(마지막 5초 깜박임), 투기장 밖이면 안쪽(벽에서 50px)으로 당김, 보스 처치 연출 때 남은 아이템 정리.
- **선택창 대기열**: 레벨업과 강화 상자를 들어온 순서대로 하나씩 연다(예: 상자 → Lv.2 → Lv.3).
- **아이템 전용 난수**(`시드:items`): 드롭 판정에 적 생성 난수를 같이 쓰면, 드롭이 생길 때마다 이후 적 등장이 달라져 4단계 시드 재현이 깨진다. 그래서 따로 둠.
- 상자를 주울 때 이미 모든 스킬이 만렙이면 그 자리에서 물약 효과로 바꿈(떨어질 때도 한 번 확인).

## v1.2 검토 — 측정으로 나온 것 (제작자 확인 필요)
8분 자동 시뮬레이션(가만히 서 있고, 거의 무적, 카드는 항상 첫 번째, 아이템은 모두 즉시 획득) 시드 11·22·33.
| 항목 | 측정 | 기획서 가정과 차이 |
|---|---|---|
| 일반 몬스터 처치 수 | 판당 약 **2,500마리**(1분 100 → 2분 300 → 4분 1,140 → 6분 2,480) | 처치 보상 상한 80G(320마리)에 **약 2분 10초면 도달** → 사실상 모든 판에서 80G 고정. 클리어 골드도 440~460G로 거의 고정 |
| 아이템 수 | 판당 약 **12~13개**(강화 상자 일반 드롭 약 2.5개 + 엘리트 1~2개) | 기획서 "500마리에 2.5개"는 맞지만, 실제 판당 처치 수가 많아 체감은 5배 |
| 보스 처치 시간 | 아이템 없음 50.2 / 58.7 / 54.0초 · 있음 52.9 / **37.2** / 60.0초 | 강화 상자 5개를 먹은 판(시드 22)은 목표 55~75초보다 크게 빨라짐. 표본 3판이라 실제 플레이로 다시 확인 |
| 엘리트 2 | 3판 중 2판 흡수(봇이 움직이지 않아 철갑어미를 못 잡음) | 사람 플레이에서 확인 필요 |
자동 봇은 사람과 다르므로(안 움직임·무적) 수치는 방향만 본다.

열린 질문
1. **처치 보상**: 20마리당 5G·상한 80G는 2분이면 끝난다. 100마리당 5G(상한 80G = 1,600마리, 약 5분)처럼 늦출지, 지금대로 둘지.
2. **일반 드롭 확률**: 판당 12개 정도가 의도인지. 줄인다면 기획서 말대로 강화 상자(0.10%)부터.
3. **기본공격 Lv.6 → 7(진화)를 강화 상자로 올릴 수 있는가**: "자동 진화 없음"과 "기본공격 Lv.1~7 강화 대상 포함"이 부딪힌다. 지금은 레벨업 카드와 똑같이 Lv.7까지 허용(Lv.7 = 기본공격 진화는 레벨만 오르면 되는 규칙이라). 액티브 진화는 아직 없음.

## 구현
| 파일 | 내용 |
|---|---|
| `src/data/progression.ts` | 강화 4종 수치, 비용 함수, 능력치 적용(`applyPermanent`), 골드 공식(`computeRunGold`), 단계 배율 |
| `src/systems/Progress.ts` | 저장(`dragon-force:progress`, 버전 1), 4단계 해금 키 이어받기, 손상 데이터 백업·복구, 값 보정, 구매, 전투별 1회 정산(`rewardedRunIds` 최근 30개) |
| `src/scenes/LobbyScene.ts` | 첫 화면: 레드 드래곤·연구소 강화 요약·해금된 단계 선택·전투 시작·연구소. `?dev=1`이면 진행 초기화(두 번 눌러 확인) |
| `src/scenes/LabScene.ts` | 연구소: 4종 카드(레벨·현재→다음 효과·비용), 골드 부족 비활성화, MAX, 구매 이펙트·임시 효과음, 로비로·바로 전투 |
| `src/scenes/GameScene.ts` | 판 시작 때 영구 강화 적용 후 고정, 35% 상한 기준 변경, 일시정지·포기, 결과 화면 골드 정산표, 연구소·로비 버튼 |
| `tests/progress.test.ts` | 단위 테스트 21개(`npm test`) |

계산 규칙: 판 시작 능력치 = 기본 × (1 + 레벨 × 증가율). 기존 패시브(용의 심장 +10, 폭풍의 날개 +13)는 *기본값의 %를 더하는* 방식이라 영구 강화와 자연스럽게 합산된다(1.20 + 0.40 = 1.60배). 피해는 모두 `stats.attack` 한 곳을 거치므로 영구 공격력은 한 번만 곱해진다.
기본값 → 만렙: 공격력 10 → 14, HP 100 → 160, 속도 260 → 286, 보석 반경 110 → 165.
