## 구현
| 파일 | 내용 |
|---|---|
| `src/data/progression.ts` | 강화 4종 수치, 비용 함수, 능력치 적용(`applyPermanent`), 골드 공식(`computeRunGold`), 단계 배율 |
| `src/systems/Progress.ts` | 저장(`dragon-force:progress`, 버전 1), 4단계 해금 키 이어받기, 손상 데이터 백업·복구, 값 보정, 구매, 전투별 1회 정산(`rewardedRunIds` 최근 30개) |
| `src/scenes/LobbyScene.ts` | 첫 화면: 레드 드래곤·연구소 강화 요약·해금된 단계 선택·전투 시작·연구소. `?dev=1`이면 진행 초기화(두 번 눌러 확인) |
| `src/scenes/LabScene.ts` | 연구소: 4종 카드(레벨·현재→다음 효과·비용), 골드 부족 비활성화, MAX, 구매 이펙트·임시 효과음, 로비로·바로 전투 |
| `src/scenes/GameScene.ts` | 판 시작 때 영구 강화 적용 후 고정, 35% 상한 기준 변경, 일시정지·포기, 결과 화면 골드 정산표, 연구소·로비 버튼 |
| `tests/progress.test.ts` | 단위 테스트 21개(`npm test`) |

계산 규칙: 판 시작 능력치 = 기본 × (1 + 레벨 × 증가율). 기존 패시브(용의 심장 +10, 폭풍의 날개 +13)는 *기본값의 %를 더하는* 방식이라 영구 강화와 자연스럽게 합산된다(1.20 + 0.40 = 1.60배). 피해는 모두 `stats.attack` 한 곳을 거치므로 영구 공격력은 한 번만 곱해진다.
기본값 → 만렙: 공격력 10 → 14, HP 100 → 160, 속도 260 → 286, 보석 반경 110 → 165.
