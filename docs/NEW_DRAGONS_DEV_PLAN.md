## 2. 기본 공격 9종 — 새로 필요한 엔진 기능
| 드래곤 | 방식 | 엔진에 더할 것 | 난이도 |
|---|---|---|---|
| 샌드 | 짧은 부채꼴 3발 + 약화 | `spread`(부채꼴 각도)·짧은 `range` — 거의 기존 탄 | 쉬움 |
| 스틸 | 되돌아오는 원반 | `returning`(최대 거리에서 드래곤 쪽으로 복귀, 갈 때·올 때 각 1회 적중) | 보통 |
| 블룸 | 적 발밑 씨앗 → 0.8초 뒤 폭발 + 속박 | `delayedGround`(대상 위치에 표시 → 지연 범위 피해) | 보통 |
| 하울 | 드래곤 둘레로 퍼지는 고리 | `ring`(반지름이 커지는 원, 적마다 1회) — 지금 `wave`를 확장 | 보통 |
| 크림슨 | 앞쪽 반원 근접 베기 + 흡수 | `melee`(부채꼴 판정·궤적 그림) + 흡수(초당 상한) | 보통 |
| 미러 | 적·투기장 벽에서 튕김 | 영구 성장의 `bounce`를 기본 공격으로 + 벽 반사 | 보통 |
| 크로노 | 표식 5개 쌓이면 폭발 | `marks`(적별 표식 수·폭발·정지 0.3초) | 보통 |
| 보이드 | 지나가며 끌어당기는 느린 구슬 | `pull`(탄 주변 일반 적 이동) + 끝 폭발 | 어려움 |
| 오로라 | 맞으면 화상·둔화·감전 번갈아 | `prism`(상태 순환, Lv.5 2개·Lv.7 3개) — 기존 상태이상 재사용 | 보통 |

**수치 기준(기존 10종과 같음)**: 공격력 100일 때 Lv.5 단일 대상 DPS가 레드(152.9)와 크게 벌어지지 않게, 대신 다수 대상·제어·생존으로 차이. 모든 수치는 데이터 파일 한 곳의 **AI 1차안**으로 표시하고 봇 측정표(`docs/DRAGONS.md` 형식)로 검증.

## 3. 출시 묶음과 작업 순서
| 묶음 | 드래곤 | 같이 여는 공용 스킬 | 이유 |
|---|---|---|---|
| A | 샌드(일반)·스틸(일반)·블룸(희귀) | 모래 회오리·강철 부메랑 + 패시브 행운의 깃털·가시 비늘 | 엔진 추가가 적어 구조(19칸 도감·출시 스위치·저장 이어받기)를 먼저 검증 |
| B | 하울(희귀)·크림슨(영웅)·미러(영웅) | 음파 진동·가시 덩굴 + 생명 흡수·쌍둥이 탄 | 고리·근접·튕김 |
| C | 크로노·보이드·오로라(전설 3) | 중력 구체·용암 분출 + 모래시계·약점 간파 | 표식·끌어당김·상태 순환(가장 복잡) |

묶음마다 순서:
1. 데이터(능력치·Lv.1~7·특성·전용 액티브·성장표) + 도형 임시 그림 → 바로 전투 가능
2. 엔진 기능 + 상태이상 → 단위 테스트(피해·지속·보스 완화)
3. 봇 측정(단계 1·10·20, 드래곤별 2판) → 수치 조정 → 측정표
4. 그림 연결(아래 4장) → 화면 확인(도감·상점 결과·해금 연출·전투)
5. 출시 스위치 켜기 → `docs/AI_LOG.md`·`LEARN.md` 기록 → 커밋

## 4. 그림 받는 방식(지금까지와 같음)
- 압축 파일이나 공유 링크로 주면 AI가 이름 확인·배경/조각 정리·크기 가공(`scripts/process_art_batchNN.py`)·연결.
- 드래곤 1종당: `portrait-<id>`(초상) · `top-<id>`(전투 탑다운, 머리가 위) · `sig-<id>`(전용 스킬 배지) · `sigil-<속성>`(해금 마법진, 가운데 비움) = **4장 × 9 = 36장**. 공용 스킬 `skill-<id>` 12장. 선택: 전투 효과 5장(원반·덩굴·음파 고리·블랙홀·극광 커튼).
- 지난 묶음에서 실제로 생긴 문제(미리 피하면 좋은 것): 합본 시트를 잘라 만든 그림은 **시트 배경이 반투명 안개로 남음**·옆 칸 조각이 섞임 → 가능하면 한 장씩 투명 배경으로. 마법진은 **가운데를 비워야** 초상이 잘 보임. 화풍이 섞이지 않게(이번 마법진 4장은 벡터 시안이라 다른 4장과 화풍 차이).
- 그림이 늦게 와도 개발은 도형 그림으로 먼저 진행한다.

## 5. 테스트로 지킬 것
- 예전 저장(10종) → 19종 저장 이어받기, 출시 안 한 드래곤은 뽑기·미션·도감에 안 나옴.
- 뽑기 10만 회: 희귀도 비율(70/22/7/1)·10회 희귀 보장·90회 전설 보장 유지, 같은 희귀도 안 균등.
- 기존 10종 DPS·레드 7레벨 일치 테스트 그대로 통과.
- 새 상태이상: 보스·엘리트 완화, 지속시간, 중첩 상한.
