단계마다 누가 무엇을 했는지 적는다. 사실만 적는다.

도구: Claude Code (코드 작성·실행 확인), 브라우저 미리보기로 동작 확인.

## 1단계 — 전투 프로토타입
**내가 판단한 것**
- 핵심 루프(이동 → 적 생성 → 자동 공격 → 사망 → 경험치 → 레벨업 → 3택)와 8단계 개발 순서
- "루프가 재미있으면 그때 그림을 넣는다" — 그림·사운드는 6단계로 미룸
- 큰 틀은 내가, 단계 사이 세부는 AI가 잡도록 역할을 나눔

**AI에게 맡긴 것 (세부 제안 → 구현)**
- 넓은 맵, 카메라 따라가기, 키보드(WASD·방향키)와 터치 조이스틱 이동, 도형으로 그린 드래곤
- 일반몹 3종의 역할 나누기: 왕국 기사(빠르고 약함, 처음부터) / 궁정 마법사(거리 두고 마력탄, 45초부터) / 성벽 골렘(느리고 단단함, 100초부터). 수치는 `src/data/enemies.ts`
- 가장 가까운 적에게 0.6초마다 자동 화염탄, 맞은 뒤 0.5초 무적, 시간이 갈수록 적이 더 자주·많이 나옴
- 게임오버 화면과 다시 시작

**확인**
- D 키 0.5초 → 오른쪽으로 61px 이동, 드래곤이 오른쪽을 봄
- 1분 50초로 건너뛰어 9초 실행 → 기사 12·마법사 3·골렘 3 등장, 마력탄 발사, 화염탄으로 처치
- 체력 0 → "드래곤이 쓰러졌다" 화면 → 누르면 체력 100·시간 0으로 새 판

## 2단계 — Survivor 시스템
**내가 판단한 것**: 몬스터 처치 → 경험치 → 레벨업 → 랜덤 3개 중 1개 선택이라는 흐름

**AI에게 맡긴 것 (세부 제안 → 구현)**
- 처치하면 경험치 보석이 떨어지고(골렘은 큰 보석 5점), 가까이 가면 빨려 오는 방식
- 경험치 곡선, 화면 맨 위 경험치 막대, Lv 표시
- 레벨업 때 게임을 멈추고 카드 3장(터치·클릭·1/2/3 키), 한 번에 여러 레벨이 오르면 차례로 선택
- 스킬 6종을 넣기 전 틀 검증용 카드 6장: 화염 강화·빠른 숨결·튼튼한 날개·용의 심장·용의 비늘·보물 감각 (`src/data/upgrades.ts`)

**확인**
- 9마리 처치 → Lv.2 카드 3장, 물리·타이머 멈춤 → "용의 심장" 클릭 → 최대 체력 120, 다시 진행
- 경험치를 한꺼번에 넣어 4레벨 상승 → 키보드로 한 번에 한 장씩 차례로 선택됨

## 3단계 — 스킬 시스템
**내가 판단한 것**: 스킬 6종(화염 / 얼음 / 번개 / 메테오 / 오브 / 방어)과 각 스킬의 성격(전방 범위, 공격+둔화, 연쇄, 주기 광역, 회전, 피해 감소)

**AI에게 맡긴 것 (세부 제안 → 구현)**
- 레벨별 수치 표(`src/data/upgrades.ts`의 `SKILL`)와 카드 설명. 예: 화염 브레스 피해 10+6×Lv, 번개 2+Lv마리 연쇄, 메테오 4레벨부터 2개
- 한 판에 공격 스킬은 4개까지, 카드 3장 중 최소 1장은 스킬이 나오게
- 화염 강화는 화염탄·브레스·메테오에 모두 적용
- 브레스: 앞쪽에 적이 없으면 가장 가까운 적 쪽으로 뿜기(가만히 서 있으면 거의 안 맞던 문제를 테스트에서 발견해 고침)
- 메테오: 무작위 후보 6곳 중 주변 적이 가장 많은 곳에 0.7초 경고 원 → 폭발
- HUD에 가진 스킬 아이콘과 레벨 표시(예: 🔥3 ⚡1)

**확인**
- 스킬 5종 Lv.3으로 12초 실행 → 브레스 4·얼음 5·번개 8·메테오 1회 피해, 12마리 처치, 둔화된 적 확인
- 오브만 Lv.3 → 오브 3개 회전, 적 2회 타격·1마리 처치
- 테스트 중 발견: 파일을 나눠 고치는 사이 화면이 먼저 갱신돼 카드 선택 오류 → 코드 반영 후 사라짐

## 4단계 — 스테이지 (엘리트·보스·클리어)
**내가 판단한 것**: 스테이지 1 "불타는 왕국" 8분, 시간대별 적 구성(0~2분 느린 병사·슬라임 / 2~4분 궁수·돌진형 / 4분 엘리트 / 4~6분 밀도 증가 / 6~8분 보스 철갑기사단장: 돌진·검기·범위), 클리어 보상 골드 300~500 (기획서 v0.1 9장)

**AI에게 맡긴 것 (세부 제안 → 구현)**
- 대화 MVP(일반몹 3종)와 기획서(4종)가 달라서, 더 최신인 기획서를 따르고 기존 적을 재배치: 기사 → 느린 병사, 마법사 → 궁수(화살), 골렘 → 4분 엘리트, 슬라임·돌격 창기병 새로 추가
- 웨이브 표(`src/data/stage1.ts`): 시간대별 생성 간격·수·종류 비율. 보스전에는 잡몹을 줄임
- 패턴: 돌격 창기병(예고선 0.6초 → 돌진), 엘리트 골렘(원형 예고 1초 → 내려찍기 28), 보스(2.6초마다 돌진 → 검기 5갈래 → 범위 내려찍기 순환)
- 모든 패턴에 "예고 → 피할 시간 → 판정"을 둠(기획서의 "회피 점검")
- 클리어 = 보스 처치. 보상 골드 = 300 + 200 × (8분까지 남은 시간 ÷ 2분) → 빨리 잡을수록 많이
- **기획서에 없어서 AI가 정한 것(확정 필요)**: 8분까지 보스를 못 잡으면 "격노"(피해 2배, 패턴 1.3배 빠름). 게임오버 때 골드는 카드로 얻은 것만

**확인 (별도 탭)**
- 0분 병사·슬라임만 → 2분 30초 궁수·창기병 추가, 화살 발사·돌진 예고 확인
- 4분 엘리트 등장 → 가까이 붙이자 내려찍기 3회, 맞았을 때 피해 28
- 6분 보스 등장 → 돌진 예고·검기·범위 내려찍기 각각 발동, 보스 체력 막대 표시
- 8분 → "격노!" 표시 / 보스 처치 → "성지 탈환!" 화면, 6분 40초 클리어 보상 433골드(계산식과 일치)
- **아직 안 한 것**: 처음부터 8분을 실제로 끝까지 해 보는 플레이 테스트(난이도·보스 체력 5200이 적당한지)
