# AI 협업 기록

넷마블네오 AI 인턴십 가이드가 묻는 것("AI에게 맡긴 일과 내가 직접 판단한 일을 구분")에 맞춰,
단계마다 누가 무엇을 했는지 적는다. 사실만 적는다.

도구: Claude Code (코드 작성·실행 확인), 브라우저 미리보기로 동작 확인.

## 0단계 — 준비 (2026-11-17)
**내가 판단한 것**
- 만들 게임: 장르만 참고한 오리지널 서바이버 슈팅, 제목 "드래곤 특공대"
- 세계관(멸망한 드래곤의 성지 탈환), 한 판 흐름, 스킬 8개 후보, MVP 범위, 이후 개발 순서 → `docs/DESIGN.md`
- "상점·뽑기·서버부터 만들지 않는다"는 우선순위
- 엔진: 웹(Phaser) — 심사자가 링크로 바로 플레이, iOS는 예전 앱처럼 Capacitor+Codemagic으로

**AI에게 맡긴 것**
- 공고·채용 사이트를 읽고 조건 정리 (엔진 조건 없음, 서류 마감 11/24 23:59, 평가 역량 3가지)
- 엔진 후보 비교(웹 Phaser / Unity / Godot)
- 프로젝트 뼈대(Vite + TypeScript + Phaser 4) 만들기

## 1단계 — 드래곤 이동
**AI에게 맡긴 것**: 넓은 맵, 카메라 따라가기, 키보드(WASD·방향키)와 터치 조이스틱 이동, 도형으로 그린 드래곤
**확인**: 브라우저에서 D 키 0.5초 → 오른쪽으로 61px 이동, 드래곤이 오른쪽을 봄
