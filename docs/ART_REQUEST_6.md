# 그림 요청서 6 — 아이콘·문양·보상 테두리·어려움 UI (2026-11-21)

요청서 4(특수 스킬·전용 액티브 아이콘)와 요청서 5(속성 문양·보상 테두리·어려움 UI)에서 **아직 안 온 그림만** 모아, 무엇이고 게임 어디에 나오는지를 자세히 적었다. 이 문서가 최신이다(요청서 4·5의 같은 항목은 이 문서로 대신).
**만드는 순서(추천)**: ① 전용 액티브 아이콘 10 → ② 속성 문양 10 + 빛줄기 1 → ③ 특수 스킬 아이콘 15 → ④ 보상 테두리 4 → ⑤ 어려움 UI 8. 일부만 와도 된다(없는 것은 지금처럼 이모지·도형으로 대신).

## 공통 규칙
- **1024×1024 PNG, 투명 배경**(안 되면 순수 초록 #00FF00 배경), 그림은 캔버스 **가운데**, **글자·숫자 없음**.
- 파일 이름은 표의 이름 그대로. 넣는 곳: 압축 파일로 주면 AI가 `art-src/`에 풀고 가공(512 또는 256 WebP)한다.
- **화풍 맞추기 첨부(매번 같이)**: `public/art/portrait-red.webp`(레드 초상) + `public/art/skill/skill-meteor.webp`(이미 받은 스킬 아이콘 — 배지 모양 기준).
- 각 표의 "GPT에 붙일 설명"은 그대로 복사해서 쓰면 된다.

지금 그 버튼 안에는 🔥🧊⚡ 같은 **이모지**가 들어가 있어서, 그 자리를 그림으로 바꾸려는 것.

## ② 속성 문양 10장 `sigil-<속성>.png` + 빛줄기 1장 `fx-unlock-rays.png`

**룬(장착해서 능력치가 오르는 아이템)이 아니다.** 능력치 없는 **장식 그림**으로, **새 드래곤을 얻었을 때 나오는 "해금 축하" 연출**에서 드래곤 초상 **뒤에 크게 깔려 천천히 도는 마법진**이다(드래곤 속성마다 다른 모양·색). 지금은 코드로 그린 노란 육각별 원이 대신하고 있다.
(나중에 드래곤 화면의 속성 표시나 도감에 같이 쓸 수 있다.)

## 받은 뒤 AI가 하는 일
압축 파일 풀기(따로 폴더) → 이름·내용 확인(그림 보고 맞춤) → 투명 여백 자르기·크기 맞춤(아이콘 256, 문양·테두리 512) → `public/art/`에 넣고 `ART_FILES` 연결 → 이모지·도형 자리를 그림으로 교체 → 브라우저에서 화면마다 확인 → 커밋·푸시.
