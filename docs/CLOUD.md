# 로그인 · 클라우드 저장 — 1단계 (2026-11-21)

제작자 결정(2026-11-20, `docs/MONETIZATION_PLAN.md`): Firebase + RevenueCat, 게스트(자동) + Sign in with Apple 연결, 앱 안 계정 삭제. 설계 `docs/STAGE8.md` 3절. 이 문서는 **1단계 구현** 기록.

## 1. 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| **1** | Firebase 익명 로그인(= 게스트 UID) + Firestore `users/{uid}` 진행 저장·동기화, 저장 충돌 선택 창, 계정 삭제가 서버 기록·로그인 계정까지 지움 | **코드 완료 — Firebase 웹 설정 값을 받으면 켜짐** |
| 2 | Sign in with Apple 연결(같은 UID 유지) → 재설치·기기 변경 복구 | 다음 |
| 3 | Cloud Functions: 선물·상자·정산·루비 지급을 서버가 처리, RevenueCat 결제 확인 | 그다음 |
| 4 | 운영 도구(관리자 웹)로 보상 발송 | 그다음 |

> ⚠ 1단계만으로는 **재설치하면 익명 계정이 새로 생겨** 서버 기록을 못 찾는다(익명 로그인은 기기 안에 저장). 재설치·기기 변경 복구는 **2단계 Apple 연결**부터. 1단계는 "서버 백업 + 같은 계정 여러 번 접속 시 충돌 처리"의 바탕.

## 2. 동작 (`src/systems/Cloud.ts`, 규칙 `src/systems/cloudSync.ts`)
- **켜지는 조건**: `VITE_FIREBASE_API_KEY`·`PROJECT_ID`·`APP_ID`가 있고, 토스 빌드·데모(`?demo=1`)가 아님. 없으면 지금처럼 **기기에만 저장**(설정 창 "☁ 이 기기에만 저장 중").
- **시작**: 게임 만들기 전에 연결(최대 4초 기다림, 넘으면 게임 먼저 시작하고 계속 연결). Firebase 코드는 켜질 때만 따로 불러옴(첫 화면 번들 그대로).
- **판단 규칙**(테스트 `tests/cloud.test.ts`):
  | 상황 | 처리 |
  |---|---|
  | 서버에 기록 없음 | 이 기기 저장을 올림(기존 기기 저장 이전) |
  | 이 기기가 이 계정과 맞춘 적 없음 + 서버에 기록 있음 | **선택 창**. 단, 이 기기가 막 설치한 빈 상태면 묻지 않고 서버 기록 받기 |
  | 서버 버전 = 이 기기 기억 | 이 기기가 바뀌었으면 올림 |
  | 서버 버전이 앞섬 | 이 기기가 그대로면 받음, 이 기기도 바뀌었으면 **선택 창** |
- **자동 덮어쓰기·합산 금지**: 선택 창(로비)에서 "이 기기 기록 / 서버 기록" 요약(단계·드래곤·골드·루비)을 보여 주고 고르게 함. 서버 기록을 받기 전 이 기기 저장은 `dragon-force:progress:before-cloud`에 보관.
- **올리기**: 진행이 바뀌면 8초 뒤 묶어서, 앱이 백그라운드로 갈 때 바로. 트랜잭션 + 버전(rev) +1 → 두 기기가 동시에 써도 한쪽만 성공, 다른 쪽은 다시 읽고 판단.
- **오프라인**: 기기 저장은 그대로 되고, 연결되면(온라인 이벤트·앱 복귀) 올림.
- **받은 저장 검사**: 기존 `loadProgress` 보정(손상·구버전 변환)을 거쳐 반영.
- **계정 삭제**: 서버 문서 → Firebase 로그인 계정 → 기기 저장 순서로 지우고 새 게스트로 시작(애플 5.1.1(v)).

## 3. 서버 데이터
`users/{uid}`: `save`(진행 저장 JSON 문자열) · `rev`(버전) · `summary`(선택 창 요약) · `schema` 1 · `platform` · `updatedAt`(서버 시각).
보안 규칙 `firestore.rules`: 본인만 읽기·쓰기·삭제, 허용 필드만, 저장 크기 400KB 미만, 버전은 정확히 +1, 다른 문서 전부 막음.
> 1단계는 재화 값도 앱이 올린다(백업 수준). 재화 조작 방지는 3단계(Functions가 재화 처리, 앱은 재화 필드 직접 쓰기 금지)에서.

## 4. 제작자가 할 일 (켜기)
1. Firebase 콘솔 → **Authentication → 로그인 방법 → 익명 사용 설정**.
2. **Firestore Database 만들기** → 위치 `asia-northeast3`(서울) 권장, 프로덕션 모드.
3. Firestore → **규칙** 탭에 저장소의 `firestore.rules` 내용을 붙여 넣고 게시(또는 `firebase deploy --only firestore:rules`).
4. 프로젝트 설정 → 내 앱 → **웹 앱 추가**(iOS 앱과 별도, 이름 아무거나) → 나오는 `firebaseConfig`의 `apiKey`·`authDomain`·`projectId`·`appId` 4개를 알려 주면 AI가 넣음.
   - 로컬: `.env.firebase.example`을 `.env.local`로 복사해 채움(git에 안 올라감).
   - iOS: Codemagic 환경 변수에 같은 이름 4개.
   - 웹 설정 값은 비밀번호가 아니라 공개돼도 되는 식별 값(보안은 위 규칙이 맡음). 그래도 저장소에는 안 올림.
5. 예산 알림(이미 Blaze) 확인.
6. 개인정보처리방침(`public/privacy.html`)에 "익명 계정 식별자(UID)와 게임 진행 기록을 서버(Google Firebase)에 보관, 계정 삭제 시 즉시 삭제" 추가 — 값 받으면 AI가 초안 작성.

## 5. 시험 목록 (값 받은 뒤)
1. 첫 실행 → 서버에 문서 생성(rev 1)
2. 플레이 → 8초 뒤 rev 증가
3. 같은 계정 두 탭에서 각각 진행 → 늦은 쪽에 선택 창
4. 오프라인 플레이 → 온라인 복귀 시 올림
5. 계정 삭제 → 서버 문서·로그인 계정 삭제, 새 UID
6. 토스 빌드에서는 꺼짐
