# 보스 개편 — 50% 변신 + 대형 스킬 (기획 초안, 2026-11-25)

제작자 요청(2026-11-25): 테스터 피드백 "엘리트·보스 공격 범위" → 보스마다 체력 50%에서 **모습이 바뀌고(변신)** 그 보스만의 **대형 스킬**이 생긴다.
예: 2단계 보스는 보이는 화면을 대각선으로 굴러다니며 부딪히면 피해, 3단계 보스는 몸에서 탄 10발씩 4번.
시트: "드래곤 특공대 출시 일정" → 탭 **보스 개편**. 그림·효과음 요청: `docs/ART_REQUEST_11.md`.

## 지금 코드
- 2~20단계 보스는 이미 체력 50%에서 2페이즈(`patterns2`, 패턴만 강화). 1단계 회색갈기는 60%. `src/systems/StageDirector.ts`의 phase 전환, 패턴은 `src/data/season1.ts`의 공통 모듈(P.dash·P.radial·P.line·P.area 등).
- 보스 그림: 1단계만 있음, 2~20단계는 도형(요청서 10 ⑤ 대기).

## 방식
**확정(11/25)**: 20종 모두 2페이즈 **컷인 애니메이션(Higgsfield)** + 컷인 뒤 전투 모습은 2페이즈 그림. 안내 문구는 "보스 이름 — 보스 2페이즈!"("변신!"은 촌스러움).

### (처음 안) Higgsfield 없이
- 변신 전·후 그림 2장 + 변신 효과음 1개(보스마다) → 코드 연출(2초 무적 → 빛남 → 섬광·파동·그림 교체·효과음 → 이름 띠).
- 글자는 게임 글자로(그림·소리에 글자·대사 없음) → 한국어·영어 따로 만들 필요 없음.

## 보스 20종 대형 스킬(안)

| 단계 | 보스 | 변신 후 대형 스킬 |
|---|---|---|
| 1 | 회색갈기 우두머리 | 늑대 분신 4마리와 화면 네 방향에서 동시 돌진(예고선) |
| 2 | 가시뿔 트렌트 | 가시 공이 되어 보이는 화면을 대각선으로 튕기며 굴러다님(벽 반사, 부딪히면 피해) — 제작자 예시 |
| 3 | 달그림자 포식자 | 몸에서 그림자 탄 10발씩 원형으로 4번 — 제작자 예시 |
| 4 | 숲의 심장 모르칸 | 화면 가장자리에서 뿌리가 안쪽으로 조여 옴(빈틈 2곳) |
| 5 | 마수왕 베르칸 | 화면 전체로 퍼지는 충격파 고리 3번 연속 |
| 6 | 철혈 장군 드라반 | 화면을 가로지르는 연속 돌진 5번(예고선) |
| 7 | 용광로 거인 그라움 | 화면 위에서 용암 덩어리 비(예고 원 12개) |
| 8 | 불꽃 기사 발테리온 | 보스 중심 십자 불기둥 회전 |
| 9 | 빙결 수호수 아이르 | 화면 절반씩 번갈아 얼음 바닥(안전한 쪽으로 이동) |
| 10 | 수정 골렘 카르디온 | 벽에 튕기는 수정 탄 원형 16발 × 3번 |
| 11 | 백설의 여왕 세리아 | 분신 3명 중 진짜를 맞혀야 끝나는 눈보라(시야 좁아짐) |
| 12 | 서리 군주 발키르 | 화면 바깥 8방향에서 얼음 창이 차례로 |
| 13 | 영혼 수확자 모르테 | 회전하는 낫 2개, 안전 범위가 좁아짐 |
| 14 | 타락한 대사제 노크스 | 화면이 어두워지고 빛 원 안만 안전(3번 이동) |
| 15 | 망령 장군 바르간 | 망령 기병대 가로 3줄 돌격(빈 줄로 피함) |
| 16 | 저주왕 아르데온 | 분신 4명이 네 귀퉁이에서 동시 광선 |
| 17 | 황금 수호자 아우렌 | 격자 모양 예고의 황금 창 비 |
| 18 | 별의 감시자 루미엘 | 대각선 별똥별 연속 낙하 + 별자리 선 광선 |
| 19 | 용의 심판자 세르칸 | 위→아래로 쓸어내리는 브레스 |
| 20 | 봉인 수호룡 에이르곤 | 지금 패턴 조합 + 화면 전체 마법진 폭발(가운데만 안전) |

## 공통 규칙(안)
- 대형 스킬은 1초 이상 빨간 예고(선·원), 피할 수 있게. 한 방 피해는 지금처럼 최대 HP 35% 상한.
- 시기(안): 앱 제출 뒤 첫 업데이트(새 기능 동결 원칙). 스킬은 그림 없이도 먼저 넣을 수 있다.
- 결정 대기: 시기, 20종 대형 스킬 내용, 2·3단계부터 할지.
