# 그림 생성 프롬프트 (GPT 이미지용, 그대로 복사)

> ⚠️ 드래곤 화풍은 아틀라스로 통일됨(2026-11-18) — 최신 요청은 [ART_REQUEST_3.md](ART_REQUEST_3.md).


만든 그림은 `C:\Users\user\Documents\ChatGPT\Dragon-Force-design\art-src\`에 **파일명 그대로** 넣는다. 크기 맞춤·배경 정리·압축·게임 연결은 AI가 한다.
GPT 이미지 크기는 정사각 1024×1024, 세로 1024×1536, 가로 1536×1024 중에서 고르면 되고, 최종 크기는 AI가 맞춘다.

## 작업 순서 (화풍 통일이 가장 중요)
1. **A. 화풍 기준**부터 만든다 → 마음에 드는 1장을 `style-anchor.png`로 저장.
2. 그다음 그림부터는 매번 `style-anchor.png`를 **첨부**하고 "첨부한 그림과 같은 화풍으로"를 앞에 붙인다.
3. 투명 배경이 필요한 그림은 생성할 때 **배경: 투명(transparent)** 옵션을 켠다. 옵션이 없으면 "단색 순수한 초록 배경(#00FF00)"으로 만들어도 된다(AI가 지움).
4. 글자·숫자·워터마크·서명이 들어가면 다시 생성한다.
