# 그림 요청서 (기획자 → 이미지 생성)

> 그대로 복사해 쓰는 GPT 프롬프트는 [ART_PROMPTS.md](ART_PROMPTS.md). 토스는 나중이라 토스 썸네일은 보류.

만든 그림은 `Dragon-Force-design/art-src/` 폴더에 아래 **파일명** 그대로 넣어 주세요. 크기 조정·배경 정리·압축·게임 연결은 AI가 합니다.
게임에 넣는 그림이라 기획서 콘셉트 이미지와 달리 **실제 에셋**으로 씁니다(이 게임을 위해 새로 생성한 그림). 생성 도구 이름과 날짜는 `docs/AI_LOG.md`에 기록합니다.

## 모든 그림 공통 규칙
- **같은 화풍**: 밝고 선명한 채색의 모바일 판타지 게임 일러스트, 또렷한 외곽선, 부드러운 명암. 1번(앱 아이콘)이 나온 뒤 그 그림을 "이 스타일로"라고 참고로 붙여서 나머지를 만들면 통일이 잘 됩니다.
- **글자·숫자·로고·워터마크 넣지 않기**(글자는 게임 코드가 씀. 그림 속 한글은 깨지기 쉬움).
- 아이콘·캐릭터는 **투명 배경 PNG**, 물체가 가운데, 가장자리에 여백 약 8%.
- 다른 게임·작품의 캐릭터나 이름을 넣지 않기.
- 레드 드래곤 기준: 진홍 비늘, 크림색 배, 주황 용암 균열, 박쥐 날개(6단계 아트 기준).
