# 앱인토스(토스판) 인앱 광고 검토 — 2026-11-26

제작자 요청: 토스 공지(인앱 광고 운영 정책 변경)를 보고 "토스판에 광고를 넣을지 검토".
**아직 결정 전**. 결정되면 이 문서에 "확정"으로 적고 구현한다.

## 1. 왜 토스판만
- 토스판은 토스 규정(디지털 상품은 토스 인앱결제만, 다른 결제·다른 앱 안내 금지) 때문에 루비 결제·패키지를 **숨겼다**(`CASH_SHOP = PLATFORM !== 'toss'`). 지금 토스판 수익원은 0.
- iOS판은 App Store 심사 메모에 "No ads, no tracking"으로 냈다 → **iOS·웹·안드로이드에는 광고를 넣지 않는다.** 광고 코드는 `src/platform/toss.ts`에만 두고 다른 빌드에는 번들되지 않게(플랫폼 창구 구조 그대로).

## 2. 토스 공지 요약(2026-11 카카오톡 안내, 제작자 캡처)
- 광고대행 약관 개정 12/26 시행.
- 지금까지는 누구나 인앱 광고를 만들 수 있었지만, **12/26부터 자연유입 방문자 500명을 모은 미니앱만 광고가 보인다.** 11/26부터 콘솔에서 자연유입 방문자 수를 볼 수 있다.
- 12/26 이후 매달 광고 품질 확인, 두 번 연속 낮으면 광고·생성 권한 30일 중단.
- → 12월 전에 서둘러 광고를 만들어도 이득이 없다(500명 조건은 그대로). **토스 출시 → 방문자 500명**이 먼저.
- 광고는 우리가 돈을 내는 것이 아니라 **수익을 받는 쪽**. 수익은 콘솔 정산 정보(사업자·계좌) 등록 뒤 월 정산(앱인토스 블로그 "사업자 등록 없이 인앱 광고를 시작해요", 정산 정책은 개발자센터).

## 3. SDK에서 확인한 것(`@apps-in-toss/web-framework` 3.10, node_modules 타입 선언)
- `GoogleAdMob.loadAppsInTossAdMob` / `showAppsInTossAdMob` / `isAppsInTossAdMobLoaded` — 이벤트에 `userEarnedReward`(보상형), `dismissed`, `failedToShow` 등.
- `showFullScreenAd`(전면), `TossAds.attachBanner`(배너), 토스 광고 ↔ AdMob 미디에이션.
- 광고 단위는 콘솔에서 만드는 **adGroupId**로 부른다.

## 4. 넣을 자리 제안(보상형만, 전면·배너는 넣지 않음)
전면 광고는 판 사이 흐름을 끊어 이탈을 늘리고, 배너는 세로 화면·토스 상단 줄과 겹친다. **사용자가 스스로 눌러 보는 보상형만**.

| 자리 | 보상 | 하루 한도(안) | 비고 |
|---|---|---|---|
| 행동력 부족 창 | 행동력 +10 | 3회 | 지금 "하루 3번 무료 5"와 같은 창에 버튼 하나 추가 |
| 전투 결과(클리어·실패) | 이번 판 골드 ×2 | 3회 | 가장 흔한 형태. 실패 50% 정산에도 적용 |
| 겨울 축제 | 행운 룰렛 1회 | 1회 | 축제 기간만. 확률은 그대로(룰렛 확률 안내에 '광고 1회' 줄 추가) |
| 상점 무료 일일 선물 옆 | 무료 개봉권 1장 | 1회 | 토스판은 상점이 비어 보여서 |

- 보상은 앱 안에서 지급(토스판은 서버 결제가 없음). 하루 한도는 KST 자정 기준, 저장 필드 하나(`adRewards: { day, counts }`).
- 광고를 못 불러오면 버튼을 숨기거나 "지금 볼 수 있는 광고가 없어요".
- 숫자(보상량·한도)는 **임시** — 제작자 확인 필요.

## 5. 순서(결정되면)
1. 콘솔: 정산 정보 확인 → 광고 그룹(보상형) 만들기 → adGroupId 받기
2. 코드: 플랫폼 창구에 `rewardedAd(slot)` 추가(토스만 구현, 나머지는 '없음') → 4절 자리 연결 → 테스트(하루 한도·실패 처리)
3. `.ait` 빌드 → QR 테스트 → 토스 검토 요청에 같이 포함
4. 토스 출시 뒤 콘솔에서 자연유입 방문자 500명 도달 확인(12/26부터 광고 노출 조건)

## 6. 결정 필요
- 넣을지 말지, 넣는다면 4절 자리 중 어디까지(추천: 행동력 + 전투 골드 ×2 두 곳부터)
- 보상량·하루 한도
